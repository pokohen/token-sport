# 전문가 검토

축구와 야구 각각 "경기와 구단 경영 전문가"의 눈으로 이 프로젝트의 경기 규칙, 시뮬레이션, 훈련, 승강제를 검토하고 고친 기록이다.

- [축구 검토](football.md)
- [야구 검토](baseball.md)

## 어떻게 검토했나

- 검토자는 사람이 아니라 **전문가 역할을 맡긴 AI 검토 에이전트** 둘이다. 한쪽은 축구, 한쪽은 야구를 맡았다.
- 검토 에이전트는 코드를 고치지 않았다. 기획 문서와 코드를 읽고, 임시 테스트로 **실제 경기 엔진을 돌려 기록을 잰 뒤** 지적 사항을 냈다. 축구는 64,800경기, 야구는 리그당 180경기씩과 300시즌 반복을 돌렸다.
- 실제 리그의 수치와 규정(잉글랜드 리그의 승강 방식, KBO의 기록 범위 등)은 검토 에이전트의 지식에 기댄 **대략의 범위**다. 일부만 웹 검색으로 확인했다. 정확한 기준이 필요하면 따로 확인해야 한다.
- 지적 사항은 "반영", "일부 반영", "보류"로 나눠 적었다. 보류한 것은 이유를 적었다.

## 가장 크게 바뀐 것

| | 전 | 후 |
|---|---|---|
| **축구 승강** | 야구와 같은 방식 (10위 강등, 9위와 하위 2위의 3전 2선승, 신청 + 인지도) | 잉글랜드 방식 (2팀 승격·2팀 강등, 2~5위 승격 플레이오프, 구장 등급) |
| **야구 승강** | 10위 강등, 9위와 하위 2위의 3전 2선승 | 그대로 두고, 2위와 3위의 **와일드카드**와 **에이스 대결 규칙**을 더함 |
| **야구 홈런** | 1부에서 팀당 경기에 2.4개 | 모든 리그에서 0.7~1.0개 |
| **축구 출장 정지** | 없음 | 퇴장 1경기, 경고 5장마다 1경기 |
| **선수 모드 훈련** | 능력치 +1 (포지션에 따라 성장 속도가 1.5배 차이) | 어떤 훈련이든 능력 +0.25, 리그 수준을 넘으면 윗 리그로 가야 함 |

검토에서 "문제없다"고 본 것도 있다. 축구의 득점 수준(경기당 2.6~3.1골)은 모든 리그에서 실제와 같았고, 야구의 36경기 시즌은 늘리지 않아도 된다는 판단이었다.

## 검토 뒤에 다시 바뀐 것

위 표와 각 검토 문서는 **검토 당시의 기록**이라 그대로 둔다. 그 뒤로 바뀐 것은 아래와 같다.

| | 검토 직후 | 지금 (1.3.0) |
|---|---|---|
| **축구 리그** | 10팀, 36라운드, 2팀 승격·2팀 강등 (2~5위 플레이오프) | **20팀, 38라운드**, 1·2위 자동 승격 + 3~6위 플레이오프로 **3팀 승격·3팀 강등** |
| **선수 모드 훈련** | 어떤 훈련이든 능력 +0.25, 리그 수준 +5까지 | 리그 한도는 없앴고, 한 번에 **6부 0.025 → 1부 0.05** (비용 0.5배 → 2.0배) |
| **농구** | 없었다 | 선수 모드로 들어왔다 → [농구 선수 모드](../11-basketball.md). 따로 전문가 검토는 하지 않았다 |
| **골키퍼 평점** | 선방 수와 무실점 | 막아 낸 골(기대 실점 − 실점)로 매긴다 → [동작 원리](../12-how-it-works.md) |
| **농구 득점** | — | 에이스가 공을 독차지하지 않게 슛 선택을 누그러뜨렸다 (능력 90 슈팅 가드 61점 → 39점) |
