# 2. 경기

## 경기 진행

✅ 경기는 1시간마다 한 번, 직접 눌러서 진행한다.

💡 진행 방식:
- 마지막 경기를 시작한 시각에서 1시간이 지나면 **경기 시작** 버튼이 켜진다.
- 내 팀이 한 경기를 치르면 같은 리그의 다른 경기들도 같은 **라운드**로 함께 진행된다. 리그 전체가 내 경기 속도에 맞춰 흘러간다.
- 시즌 36경기면 최소 36시간이 걸린다. 하루에 몇 경기씩 하면 1~2주에 한 시즌이 끝난다.

✅ 경기 기회는 1시간마다 1개씩 쌓이고, **최대 3경기**까지 모아 둘 수 있다.
- 3개가 찬 상태에서는 더 쌓이지 않는다.
- 💡 쌓인 경기도 한 번에 한 경기씩 실시간 중계로 진행한다. 한 경기가 끝나야 다음 경기를 시작할 수 있다.
- 💡 홈 화면과 상단바 툴팁에 남은 경기 기회(예: ⚾⚾○)를 보여준다.

## 토큰으로 바로 경기

✅ 경기 기회가 없을 때, 한 시간을 기다리지 않고 **토큰으로 경기 기회를 하나 사서** 바로 치를 수 있다.

- 값: **300만** (구단 모드는 구단 자금, 선수 모드는 훈련 포인트). 가격 난이도가 적용된다.
- **연달아 사면 두 배씩** 오른다: 300만 → 600만 → 1,200만 → … (최대 1억 9,200만).
- 경기 기회가 **저절로 하나 생기면 처음 값으로** 돌아간다. 한 시간에 하나쯤은 싸게 살 수 있고, 몰아서 하려면 비싸진다.
- 경기 기회가 남아 있을 때는 살 수 없다 (있는 것부터 쓴다).
- 다음 경기 카드의 "바로 경기" 버튼을 누르면 사고 곧바로 경기가 시작된다.

## 결과 바로 보기

✅ 진행 중인 경기를 **토큰을 내고 곧바로 끝까지** 치른다. 경기 탭 맨 위 배속 카드에 버튼이 있다.

- 값: **100만** (구단 모드는 구단 자금, 선수 모드는 훈련 포인트). 가격 난이도가 적용되고, 여러 번 써도 오르지 않는다.
- 경기 시작 전이든 도중이든 쓸 수 있다. 도중이면 남은 시간만 건너뛴다.
- 경기는 시작할 때 정해진 시드로 흘러가므로 **결과는 끝까지 지켜봤을 때와 같다**. 다만 건너뛴 뒤로는 플레이 스타일을 바꿀 수 없다.
- 장부에는 "결과 바로 보기" 지출로 남는다.

토큰을 많이 쓰는 사람이 하루 만에 시즌을 끝내 버리지 않게 값이 오르도록 했다. 선수 모드에서는 훈련에 쓸 포인트와 저울질하게 된다.

## 실시간 중계

✅ 경기는 결과가 바로 나오지 않는다. 실제 야구처럼 시뮬레이션이 **한 구 한 구** 실제로 돌아간다.

✅ **배속이 있다**: 1× · 2× · 4× · 8×. 경기 탭의 배속 카드에서 고르고, 경기 도중에도 바꿀 수 있다. 고른 배속은 다음 경기에도 이어진다.

- 배속은 **기다리는 시간만** 줄인다. 공 하나하나를 그대로 시뮬레이션하고 문자 중계도 모두 나온다. 같은 경기는 어떤 배속으로 봐도 결과가 같다.
- 결과로 바로 건너뛰는 기능은 없다.
- 처음에는 "배속 없음"이 원칙이었다. 한 경기 15분이 너무 길다는 의견으로 바꿨다.

| 배속 | 한 경기에 걸리는 시간 (대략) |
|---|---|
| 1× | 15분 |
| 2× | 8분 |
| 4× | 4분 |
| 8× | 2분 |

💡 진행 속도 (1배속): 공 하나에 약 3초, 한 경기(약 280구)에 **약 15분**.

- 이닝 교대, 투수 교체, 득점 장면에서는 잠깐 멈췄다 간다.
- 팝오버를 닫아도 경기는 백그라운드에서 계속 진행된다. 다시 열면 지금 상황부터 보인다.

### 중계 화면

```
┌──────────────────────────────────────────┐
│  1 2 3 4 5 6 7 8 9   R  H  E             │
│ 원정 0 0 1 0 2 0 0      3  7  0          │
│ 홈   1 0 0 0 1 0        2  5  1          │
├──────────────────────────────────────────┤
│        ◇ 2루                  7회초      │
│   ◇ 3루     ◆ 1루            B ●●○       │
│        ⌂ 홈                   S ●○       │
│                              O ●○        │
├──────────────────────────────────────────┤
│ 투수 박○○  78구  │ 타자 김○○  2타수 1안타 │
├──────────────────────────────────────────┤
│ 3구째 슬라이더, 바깥쪽 헛스윙!            │
│ 2구째 직구 146km, 볼                      │
│ 1구째 커브, 스트라이크 (루킹)             │
└──────────────────────────────────────────┘
```

- **스코어보드**: 이닝별 점수, 안타(H), 실책(E)
- **다이아몬드**: 주자 위치, 타구 방향 표시
- **볼카운트**: 볼·스트라이크·아웃
- **매치업**: 현재 투수(투구 수)와 타자(오늘 기록)
- **문자 중계**: 투구마다 구종, 구속, 결과
- 💡 **타 구장 소식**: 같은 라운드의 다른 경기도 동시에 돌아가며, 중계 하단에 점수가 흘러간다 (예: "부산 4 : 2 대구 6회말")

### 경기 중 상단바

상단바 표시 설정(자금 / 오늘 사용량 / 다음 경기)과 상관없이 경기 상황을 보여준다 → [메인](01-main.md#상단바-메뉴바)

- 💡 경기 중: 실시간 스코어 `⚾ 3:2 7회초`. 득점하면 잠깐 반짝인다.
- ✅ 경기가 끝나면 `⚾ 경기 종료`를 표시한다. 💡 `승 5:3`처럼 결과를 짧게 붙이고, 팝오버를 열어 확인할 때까지 남겨 둔다.
- 💡 알림(설정에서 끌 수 있음): 내 팀 득점, 역전, 경기 종료.

### 감독 개입

💡 처음에는 개입하지 않는다. 라인업, 선발 투수, 투수 운용 방침(교체 기준 투구 수, 마무리 투입 조건)은 경기 전에 정하고, 경기는 그 방침대로 흘러간다.

💡 나중에 넣을 수 있는 작전: 번트, 도루, 고의사구, 투수 교체, 대타. 실시간 중계라서 경기 중 개입을 붙이기 좋다.

## 야구 규칙

✅ 기본 야구 규칙을 따른다. 정규시즌 운영은 KBO 방식을 참고한다.

| 항목 | 규칙 |
|---|---|
| 이닝 | 9이닝, 이닝당 3아웃 |
| 말 공격 생략 | 9회초가 끝났을 때 홈팀이 이기고 있으면 9회말을 하지 않음 |
| 끝내기 | 9회말 이후 홈팀이 앞서는 순간 경기 종료 |
| 연장 | 💡 KBO 정규시즌처럼 최대 11회. 그래도 동점이면 무승부 |
| 승부치기 | 없음 |
| 지명타자 | 사용 (투수는 타석에 서지 않음) |
| 콜드게임 | 💡 시민 리그(4~6부)만 5회 이후 10점 차, 7회 이후 7점 차 |

| 승리 투수 | 선발은 **5이닝**(콜드게임은 4이닝)을 던져야 승리 투수가 된다. 못 채웠으면 뒤이어 나온 첫 구원 투수가 승리 투수다 |

❓ 콜드게임을 하위 리그에만 둘지, 아예 뺄지

## 시뮬레이션

✅ 투구 단위로 실제로 시뮬레이션한다. 결과를 미리 정해 놓고 보여주는 것이 아니다.

### 한 구의 흐름

```
투수: 구종·코스 선택 → 투구 (구속, 제구 오차)
   │
타자: 스윙 여부 판단 (선구안)
   │
   ├─ 안 침 → 볼 / 스트라이크 (존 안이면 루킹 스트라이크)
   └─ 침   → 헛스윙 / 파울 / 인플레이
                                 │
                       타구 생성: 속도·각도·방향 (파워, 컨택)
                                 │
                       수비 판정: 수비 범위·어깨 → 아웃 / 안타 / 실책
                                 │
                       주자 진루: 주력, 타구 위치, 송구
```

| 단계 | 쓰는 능력치 |
|---|---|
| 구종·코스 선택 | 투수 성향, 볼카운트 (불리하면 존 안쪽) |
| 구속·제구 | 구위, 제구, 남은 체력 |
| 스윙 판단 | 타자 선구안, 볼카운트 |
| 맞히기 | 타자 컨택 vs 투수 구위·변화구 |
| 타구 질 | 타자 파워, 맞힌 정도 |
| 수비 | 야수 수비·어깨, 타구 방향 |
| 진루 | 주자 주력, 외야수 어깨 |

선수 능력치는 → [선수 영입](05-player-recruitment.md#능력치)

### 투구 사이 이벤트

💡 공과 공 사이에도 일이 일어난다: 도루 시도, 견제, 폭투·포일, 투수 교체, 대타·대주자.

### 체력과 투수 교체

- 투수는 공을 던질수록 체력이 줄고, 구속과 제구가 떨어진다.
- 💡 투구 수, 실점, 체력을 보고 투수 운용 방침에 따라 불펜으로 바꾼다.
- ✅ 선발 투수는 등판 뒤 쉬어야 다시 선발로 나온다 (시민 리그 2경기, 3부부터 4경기). 내가 다음 경기 선발을 지정할 때도 쉬는 중인 투수는 고를 수 없다.
- ✅ 불펜 투수는 28구를 던지거나 4실점하면 바뀐다. 직전 경기에 25구 넘게 던졌거나 이틀 연속 나온 불펜은 다음 경기에 맨 뒤로 밀려, 꼭 필요할 때만 나온다.

### 기타

- ✅ 홈 경기 보정: 홈팀은 작은 보정(+0.5% ~ +2.5%)을 받는다. 경기장 레벨이 높을수록 커진다 → [구단 운영](04-club-management.md#경기장). 가장 큰 경기장에서 같은 전력끼리 홈 승률이 54~55%가 되는 수준이다 (실제 야구는 51~54%).
- 💡 같은 입력이면 같은 결과가 나오도록 경기마다 시드를 저장한다 (재현과 디버깅용). 앱을 껐다 켜도 진행 중인 경기를 이어서 볼 수 있다.
- 다른 경기도 같은 엔진으로 투구 단위로 돌린다. 화면에 그리지 않을 뿐이다 → [세계 시뮬레이션](06-world-simulation.md)

### 득점 환경

전문가 검토 때 리그별 기록을 재서 공식을 고쳤다 → [야구 검토](review/baseball.md).

- **홈런**은 타자의 파워와 투수의 구위 **차이**로 정한다. 예전에는 파워에만 지수로 반응해, 능력치가 다 같이 높은 1부에서 팀당 경기에 2.4개씩 나왔다 (실제는 0.7~1.0개).
- **제구**가 좋은 투수는 홈런과 직선타를 덜 맞는다. 예전에는 제구가 볼넷에만 영향을 줘서 능력에 들어가는 비중만큼 값을 하지 못했다.
- **수비**는 타자의 발·힘·컨택과 견주어 본다. 능력치가 다 같이 높은 리그라고 안타가 줄지 않는다.
- **볼넷**을 늘렸다 (타석의 6.5~7.4% → 8~9%).
- **도루**는 주자의 발과 포수 어깨의 차이로 뛴다. 예전에는 주력이 50을 넘어야 뛰어서 4~6부에는 도루가 없었다.

| 지표 (팀당 한 경기) | 1부 | 3부 | 6부 | 실제 야구 |
|---|---|---|---|---|
| 득점 | 4.2 | 4.5 | 4.6 | 4.4~5.4 |
| 홈런 | 0.9 | 0.9 | 0.9 | 0.7~1.0 |
| 타율 | .248 | .256 | .266 | .260~.277 |
| 출루율 | .320 | .324 | .322 | .335~.352 |
| 볼넷 비율 | 9.5% | 9.1% | 7.5% | 9~10% |
| 도루 | 0.4 | 0.2 | 0.2 | 0.6~0.9 |

한 리그 180경기씩 잰 값이라 ±0.3점쯤 흔들린다. 출루율과 도루는 아직 조금 낮다.

## 친선 경기

✅ 시즌이 끝나면 오프시즌에 친선 경기를 약 5번 치른다 → [리그](03-league.md#오프시즌)

| 항목 | 친선 경기 |
|---|---|
| 진행 | 정규시즌과 같음. 1시간마다, 최대 3경기 쌓임, 실시간 중계 |
| 상대 | 💡 다른 리그 팀 중 무작위. 상위 리그 팀과 붙어 볼 수 있는 기회 |
| 순위·기록 | 반영하지 않음 (친선 기록은 따로) |
| 선수 성장 | 💡 경험치 절반 |
| 인지도 | 💡 상위 리그 팀을 이기면 조금 오름 |
| 수입 | 💡 홈이면 관중 수입 절반 |
| 쓰임 | 새로 영입한 선수 시험, 유망주 출전, 라인업 실험 |

- ✅ 경기가 끝날 때마다 이적 시장 소식(오퍼, 협상 결과)이 들어온다 → [선수 영입](05-player-recruitment.md#이적-시장)

## 경기 결과의 영향

| 항목 | 승리 | 무승부 | 패배 |
|---|---|---|---|
| 순위 | 승 +1 | 무 +1 | 패 +1 |
| 인지도 | 💡 +3 | +1 | +0 |
| 선수 경험치 | 출전 선수 모두 받음. 활약도에 따라 추가 | | |
| 관중 수입 | 💡 홈 경기만. 경기장 수용 인원 × 인지도 비율 | | |

💡 순위는 KBO처럼 **승률 = 승 / (승 + 패)** 로 정하고 무승부는 빼고 계산한다.

## 기록

💡 시즌별로 쌓는 기록:
- 팀: 승·무·패, 득점, 실점, 팀 타율, 팀 평균자책점
- 타자: 타율, 홈런, 타점, 도루, OPS
- 투수: 승, 패, 세이브, 평균자책점, 탈삼진, 이닝, 투구 수

💡 시즌이 끝나면 리그 시상(MVP, 홈런왕, 다승왕 등)을 하고, 수상하면 인지도 보너스를 준다.
