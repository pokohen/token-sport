# 테스트 안내

자동 테스트가 지키는 것과, 사람이 직접 눌러 봐야 하는 것을 나눠 적는다.
아래 수동 항목은 **아직 아무도 확인하지 않은 것**이다. 확인하면 `[x]`로 바꾼다.

지금은 **선수 키우기**(야구 선수, 축구 선수)가 중심이다. 1~6번과 8~13번이 여기에 해당한다. 7번(기존 구단 모드)은 앱에서 뺐으므로 확인하지 않는다 (자동 테스트는 계속 돈다).

## 준비

진짜 저장 파일을 건드리지 않게 저장 위치를 바꿔 실행한다. 선수 모드와 축구 구단의 저장 파일도 같은 폴더에 생긴다.

```sh
mkdir -p /tmp/tb-test
TOKEN_BASEBALL_SAVE=/tmp/tb-test/save.json swift run TokenBaseball
```

처음부터 다시 하려면 `/tmp/tb-test` 폴더를 지운다. (`Scripts/reset.sh`는 진짜 저장 폴더를 옮기는 명령이라, 이렇게 저장 위치를 바꿔 시험할 때는 쓰지 않는다.)

## 자동 테스트

```sh
swift test                                    # 전체 (5~6분)
swift test --filter Career                    # 선수 모드만 (2분쯤)
swift test --filter UsageReader               # 토큰 읽기만
TB_STRESS=1 swift test --filter StressTests   # 여러 시드 장기 시뮬레이션
```

앱 흐름 자가 점검도 있다. 화면 없이 앱 상태를 직접 몰아서 네 가지 모드의 만들기, 훈련, 경기, 모드 전환, 다시 켜기(경기 도중 포함)가 실제 저장 파일과 함께 돌아가는지 본다. 지정한 폴더는 비워지므로 빈 폴더를 준다.

```sh
swift build && TOKEN_BASEBALL_SELFTEST=/tmp/tb-selftest .build/debug/TokenBaseball
```

자동 테스트가 지키는 것:

- 야구 구단 모드가 같은 시드에서 늘 똑같이 흘러간다 (지문 비교). 예전 엔진으로 만든 저장 파일도 지금 코드로 읽어 이어 간다
- 농구: 경기 엔진의 득점·성공률·출전 시간, 반드시 승부가 나는지, 벤치 출전 시간 보장, 두 시즌 연속 진행, 경기 도중 저장
- 선수 모드 (야구·축구): 선수 만들기, 출전 규칙, 평점, 훈련 비용과 횟수 제한, 추가 훈련, 한계 돌파, 이적·재계약·무소속, 은퇴와 새 선수, 저장 칸, 세 시즌 연속 진행
- 승강: 야구의 와일드카드와 승강 플레이오프, 축구의 2팀 승격·2팀 강등과 승격 플레이오프(두 경기 합산, 중립 결승), 구장 등급
- 전문가 검토 뒤의 규칙: 득점 환경(야구 득점·홈런·볼넷, 축구 득점·홈 승률·퇴장), 선발승 5이닝, 선발 휴식, 불펜 휴식, 출장 정지, 축구 이적 기간, 나이 곡선
- 토큰 읽기: 네 가지 도구의 기록 형식, 중복 제거, 깨진 줄 건너뛰기

자동 테스트가 **지키지 못하는 것**: 화면, 버튼과 입력 칸을 눌렀을 때의 동작, 실제 토큰 로그, 실시간 중계의 속도와 배속, 알림. 아래에서 직접 본다.

## 꼭 확인할 것

### 1. 선수 만들기 화면 (가장 먼저)

화면 그림으로 생김새는 확인했지만, 한 번도 직접 눌러 보지 못한 부분이다.

- [ ] 처음 화면에서 "야구 선수" 카드를 고르고 "다음"을 누르면 선수 만들기 화면이 나온다
- [ ] 이름을 비우고 "커리어 시작"을 누르면 "선수 이름을 입력해 주세요"가 나오고 넘어가지 않는다
- [ ] 타자 ↔ 투수를 바꾸면 포지션 버튼이 바뀌고, 고른 포지션이 표시된다
- [ ] 타석(우타·좌타), 투구(우투·좌투), 출신을 바꾼 대로 선수가 만들어진다 (홈 탭의 선수 카드에서 확인)
- [ ] 타자, 선발 투수, 불펜 투수로 각각 한 번씩 만들어 본다 (다시 만들려면 `save-baseball-player.json`을 지운다)
- [ ] "시작 포인트"의 +/− 버튼으로 모두 5개, 능력치 하나에 2개까지만 들어가고, 포지션(타자 ↔ 투수 포함)을 바꾸면 0으로 돌아간다
- [ ] 포인트를 넣은 능력치가 만든 선수의 훈련 탭에서 그만큼(하나에 +3) 높게 나온다
- [ ] 홈 탭의 선수 카드에 "타고난 재능"이, 소식에 "스카우트 평가"가 나온다. 여러 번 만들어 보면 시작 능력과 재능 등급이 달라진다
- [ ] 만든 뒤 홈 탭에 선수 카드, 훈련 포인트 100,000 P, 시즌 목표, 다음 경기가 나온다

### 2. 토큰이 훈련 포인트로 쌓이는지

- [ ] Claude Code를 쓰면 20초쯤 뒤에 훈련 포인트가 오른다
- [ ] 홈 탭의 "오늘 번 포인트"가 선수를 만든 뒤에 쓴 토큰만 센다
- [ ] 상단바에 `1.2M P`처럼 포인트가 나오고, 마우스를 올리면 "훈련 포인트"가 보인다
- [ ] **Gemini CLI**를 쓰는 맥에서 포인트가 오른다 (실제 로그로 확인한 적이 없다)
- [ ] **opencode**를 쓰는 맥에서 포인트가 오른다 (실제 로그로 확인한 적이 없다)
- [ ] 같은 토큰이 두 번 세어지지 않는다 (앱을 껐다 켜도 포인트가 갑자기 늘지 않는다)

### 3. 훈련

- [ ] 훈련 버튼을 누르면 버튼에 적힌 만큼 능력치가 오르고 포인트가 줄어든다. 능력(선수 카드의 숫자)은 어떤 훈련이든 0.25 오른다
- [ ] 같은 훈련을 다시 하면 버튼의 비용이 조금 올라 있다
- [ ] 훈련을 많이 하다 보면 가끔(100번에 한 번꼴) "크리티컬!"이 뜨고 그 능력치가 세 배 오른다. "내 선수" 카드의 크리티컬 횟수가 하나 늘어난다
- [ ] 다섯 번 훈련하면 모든 훈련 버튼이 꺼지고, 경기를 한 번 치르면 다시 켜진다
- [ ] 포인트가 모자라면 버튼이 꺼지고, 마우스를 올리면 이유가 나온다
- [ ] 설정의 가격 난이도를 바꾸면 훈련 비용이 따라 바뀐다
- [ ] 한계 돌파 훈련은 포인트가 3,000만 이상일 때만 켜진다

### 4. 경기와 중계

- [ ] "경기 시작"을 누르면 중계가 시작되고, 스코어보드 아래에 "내 선수" 줄이 나온다
- [ ] 타자: 타석에 설 때마다 내 선수 줄의 기록이 바뀌고, 문자 중계의 내 선수 장면이 강조된다
- [ ] 선발 투수: 등판하는 날에는 1회부터 던지고, 쉬는 날에는 홈 탭에 "등판하지 않는 날"이라고 미리 나온다
- [ ] 불펜 투수: 선발이 내려간 뒤 가장 먼저 올라온다
- [ ] 경기가 끝나면 경기 탭 "지난 경기"에 평점, 감독 신뢰 변화, 연봉이 나온다
- [ ] 중계 도중 앱을 껐다 켜면 그 경기가 이어진다
- [ ] 팝오버를 닫아도 경기가 진행되고, 상단바에 스코어가 나온다

### 5. 계약과 이적

제안은 확률로 오기 때문에 시간이 걸린다. 오프시즌(시즌이 끝난 뒤 친선 5경기)에 가장 자주 온다.

- [ ] 제안이 오면 홈 탭에 주황색 알림이 뜨고, 누르면 커리어 탭으로 간다
- [ ] 수락하면 소속 구단이 바뀌고, 다음 경기를 그 구단에서 치른다
- [ ] 투수가 구단을 옮긴 뒤에도 곧바로 등판한다 (고친 버그라서 한 번 더 본다)
- [ ] "연봉 올려 달라고 하기"는 제안마다 한 번만 된다
- [ ] 답하지 않은 이적 제안은 다음 경기가 끝나면 사라진다
- [ ] "이적 요청"을 누르면 감독 신뢰가 10 떨어지고 버튼이 꺼진다
- [ ] 계약이 끝났는데 재계약하지 않으면 무소속이 되고, 입단 제안 중 하나를 골라야 경기를 할 수 있다

### 6. 모드 전환과 저장

- [ ] 설정 탭 "모드"에서 야구 구단 ↔ 야구 선수 ↔ 축구 구단을 오갈 수 있다
- [ ] 다른 모드에 다녀와도 선수가 그대로 있다
- [ ] 쉬는 동안 쓴 토큰은 돌아왔을 때 포인트로 들어오지 않는다
- [ ] 쉬는 동안에는 경기 기회가 쌓이지 않는다
- [ ] 저장 폴더에 `save.json`, `save-football.json`, `save-baseball-player.json`이 따로 생긴다
- [ ] **예전부터 하던 야구 구단 저장 파일**을 복사해 와서 열어도 그대로 이어진다 (원본은 건드리지 않는다)

### 7. 기존 구단 모드가 그대로인지

선수 모드를 넣으면서 경기·시즌 코드를 건드렸다. 자동 테스트가 지키고 있지만 화면은 한 번 본다.

- [ ] 야구 구단: 홈, 경기, 리그, 구단, 선수, 설정 탭이 예전과 같다
- [ ] 야구 구단: 경기 탭에 "투수 운용 방침"이 그대로 있다
- [ ] 야구 구단: 리그 탭에서 다른 팀 선수에게 이적 제안을 보낼 수 있다
- [ ] 축구 구단: 경기 한 번을 끝까지 치른다

### 8. 축구 선수 모드

- [ ] 처음 화면에서 "축구 선수"를 고르면 포지션 네 개와 출신만 묻는 만들기 화면이 나온다
- [ ] 포지션을 누르면 설명이 바뀐다 (골키퍼는 "가장 오래 걸리는 포지션" 안내)
- [ ] 홈 탭의 다음 경기 안내가 "선발" 또는 "몇 분쯤 교체"로 나온다
- [ ] 벤치에서 시작한 경기: 중계의 내 선수 줄이 "벤치에서 대기 중"이다가, 안내된 시간쯤에 교체 문구와 함께 평점으로 바뀐다
- [ ] 경기 탭의 플레이 스타일을 바꾸면 설명이 바뀌고, 앱을 껐다 켜도 남아 있다
- [ ] 욕심내기로 몇 경기 하면 슈팅 수가 눈에 띄게 는다
- [ ] 골키퍼: 주전이 아니면 네 경기에 한 번만 나오고, 나머지 경기는 "출전하지 않았습니다"로 끝난다
- [ ] 커리어 탭의 "주전 경쟁" 카드에 같은 포지션 선수들과 선발 자리 수가 나온다
- [ ] 퇴장당한 다음 경기에 홈 탭 안내가 "출장 정지"로 나오고 그 경기에 나오지 않는다

### 9. 전문가 검토 뒤에 바뀐 것

- [ ] 선수 모드 훈련 버튼이 "+0.8 · 400.0K P"처럼 능력치 증가량을 보여 준다
- [ ] 6부에서 능력이 45를 넘어도 훈련 버튼이 켜져 있다 (리그 한도는 없앴다)
- [ ] 설정 탭의 "추가 훈련"을 켜면 다섯 번을 다 쓴 뒤에도 훈련 버튼이 켜지고, 버튼의 비용이 1.5배, 2.25배로 오른다. 끄면 다시 꺼진다. 다음 경기 뒤에는 처음 값이다
- [ ] 야구 선발 투수: 등판하지 않은 날 뒤에는 남은 훈련이 3/2로 나온다 (한 번 더)
- [ ] 야구 구단: 방금 던진 선발을 "다음 경기 선발"로 고르면 "아직 쉬어야 합니다"가 나온다
- [ ] 야구 구단: 리그 탭 안내가 "2위와 3위는 와일드카드"로 나온다
- [ ] 축구 구단: 리그 탭에 "승격 조건: 구장 등급" 카드가 나오고 신청 버튼이 없다
- [ ] 축구 구단: 퇴장당한 선수가 로스터에 "출장 정지"로 표시되고 다음 경기 선발에서 빠진다
- [ ] 축구 구단: 오프시즌에 "유소년 승급" 후보 세 명이 온다
- [ ] 축구 구단: 4~16라운드에는 이적 시장이 닫혀 있다

### 10. 업데이트와 초기화 명령

진짜 저장 폴더를 다루는 명령이다. 시험 삼아 돌릴 때는 `TOKEN_BASEBALL_DATA_DIR=임시 폴더`를 앞에 붙이면 그 폴더를 저장 폴더로 보고 동작한다.

- [ ] `Scripts/update.sh`: 최신 코드를 받고 앱을 다시 만든 뒤, 앱을 열면 하던 구단·선수가 그대로다
- [ ] `Scripts/update.sh`: 이미 최신이면 "이미 최신입니다"가 나오고 앱만 다시 만든다
- [ ] `Scripts/reset.sh`: 무엇을 할지 보여 주고 묻는다. `n`이면 아무것도 바뀌지 않는다
- [ ] `Scripts/reset.sh`: `y`면 저장 폴더가 `TokenBaseball-backup-날짜-시각`으로 옮겨지고, 앱을 열면 처음 화면이 나온다
- [ ] 백업 폴더 이름을 `TokenBaseball`로 되돌리면 예전 구단·선수가 다시 나온다
- [ ] 파일을 하나 고친 상태에서는 두 명령 모두 멈추고 고친 파일 목록을 보여 준다

앱 안의 초기화 (설정 탭 → 초기화):

- [ ] "○○ 처음부터 다시"를 누르면 **카드 안에** 붉은 확인 줄이 펼쳐진다 (따로 창이 뜨지 않는다). 은퇴 버튼도 같다
- [ ] "○○ 처음부터 다시": 한 번 더 묻고, 확인하면 처음 화면이 나온다. 다른 모드로 가 보면 그쪽 선수는 그대로다
- [ ] "전체 초기화": 확인하면 모든 모드가 비어 있다
- [ ] 취소하면 아무것도 바뀌지 않는다
- [ ] "저장 폴더 열기" → `backups/날짜-시각/`에 예전 저장 파일이 있다. 앱을 끄고 그 파일을 원래 자리로 옮긴 뒤 켜면 예전 선수가 나온다
- [ ] 경기 중에 초기화해도 앱이 멈추지 않는다

### 축구 20팀 리그와 예전 저장 파일

- [ ] 새로 만든 축구 선수: 리그 탭 순위표에 20팀이 나오고, 다음 경기 카드에 "/ 전체 38라운드"가 나온다
- [ ] 리그가 10팀이던 때의 축구 선수 저장 파일로 켜면 그대로 이어진다 (10팀, "/ 전체 36라운드")
- [ ] 그 저장으로 시즌을 끝내고 새 시즌이 시작되면 소식에 "리그 확장"이 뜨고, 순위표가 20팀, 38라운드가 된다
- [ ] 컵대회 카드: 새 세계에서는 "120개 구단", 1라운드 다음이 "64강"이다

### 11. 새 버전 알림

`Scripts/make-app.sh`로 만든 앱에서만 동작한다. 이 앱에는 아이콘(`Resources/AppIcon.icns`, 부채꼴 "토큰 스포츠")이 들어가서 Finder와 알림에 나온다. 터미널에서는 이렇게 확인할 수 있다.

```sh
# 예전 버전으로 빌드한 것처럼 확인: 새 버전이 있다고 나와야 한다
TOKEN_BASEBALL_CHECK_UPDATE=1 TOKEN_BASEBALL_BUILD_COMMIT=f3800d7b981616bd24fa0b8c151eff76b0aa4033 .build/debug/TokenBaseball
```

- [ ] 최신 코드로 만든 앱: 설정 탭 "업데이트" 카드에 "최신 버전입니다"가 나온다
- [ ] 예전 코드로 만든 앱: 켜고 잠시 뒤 알림이 한 번 오고, 팝오버 위쪽에 "새 버전이 있습니다" 줄이 나온다
- [ ] 그 줄을 누르면 설정 탭으로 가고, 카드에 바뀐 내용과 `Scripts/update.sh`가 나온다
- [ ] "명령 복사"를 누르면 터미널에 붙여 넣을 수 있다
- [ ] 같은 업데이트로 알림이 두 번 오지 않는다 (앱을 껐다 켜도)
- [ ] "새 버전 자동 확인"을 끄면 표시가 사라지고, "지금 확인"은 여전히 된다
- [ ] 인터넷이 끊겨 있어도 앱이 멈추지 않는다 (카드에 "확인하지 못했습니다")

앱 안에서 업데이트 (배포 파일로 설치한 앱, 새 버전이 올라와 있을 때):

- [ ] 업데이트 카드의 "업데이트 내용"을 펼치면 변경 목록이 나오고, "웹에서 자세히 보기"가 배포 페이지를 연다
- [ ] "지금 업데이트"를 누르면 "내려받는 중…" → "확인하는 중…" 뒤에 앱이 꺼졌다가 새 버전으로 다시 열린다. 하던 선수가 그대로다
- [ ] 다시 열린 앱의 업데이트 카드에 새 버전 번호가 나온다
- [ ] 경기 중에는 버튼이 꺼져 있다
- [ ] 인터넷을 끊고 누르면 이유가 나오고 앱은 그대로다

컨디션, 기세, 라이벌, 실전 경험:

- [ ] 홈 탭 선수 카드에 "다음 경기 컨디션"이 나오고, 경기를 치를 때마다 바뀐다
- [ ] 평점 7.0 이상을 세 경기 이어 가면 "기세" 줄이 생기고 소식에 한 줄이 뜬다
- [ ] 커리어 탭에 "라이벌" 카드가 있고, 그 구단과 경기한 뒤 맞대결 전적이 바뀐다
- [ ] "바로 경기"로 치른 경기가 끝나면 결과에 "실전 경험: 능력 +0.xx"가 나온다. 평소 경기에는 나오지 않는다
- [ ] 경기 기회가 없을 때 "다음 경기까지 ○분 · ○시 ○분에 가능"과 막대가 나오고, 시간이 지나면 줄어든다
- [ ] 상단바 숫자를 "다음 경기"로 두면 "경기까지 23분"처럼 나온다

도트 공:

- [ ] 설정에서 "훈련 애니메이션"을 끄면 상단바에 도트 야구공(축구 선수는 축구공)이 나오고, 켜면 다시 훈련하는 모습이 나온다
- [ ] 경기 중에는 상단바 점수 앞에 도트 공이 나온다 (그림 문자 ⚾⚽가 아니다)
- [ ] 다음 경기 카드의 남은 경기 기회, 설정의 모드 목록, 처음 화면의 모드 카드에 도트 공이 나온다

컵대회:

- [ ] 리그 탭에 "컵대회" 카드가 있고, 다음 라운드가 리그 몇 라운드 뒤인지 나온다
- [ ] 리그 4라운드를 마치면 다음 경기가 "컵대회 1라운드"로 바뀐다 (1부 강팀이면 쉰다). 치른 뒤 리그 라운드 번호는 그대로다
- [ ] 컵 경기는 비기지 않는다 (야구 연장, 축구 연장·승부차기)
- [ ] 이기면 결과에 "컵대회 … 통과. 명성 +1", 지면 "탈락"이 나오고, 떨어진 뒤에는 컵 경기가 더 나오지 않는다
- [ ] 8강부터 카드에 전체 대진이 나오고, 결승 뒤에 우승팀이 나온다

명성 활동과 이름 바꾸기:

- [ ] 커리어 탭 "명성 활동": 버튼을 누르면 포인트가 줄고 명성이 버튼에 적힌 만큼 오른다
- [ ] 한 번 하면 세 버튼이 모두 꺼지고, 경기를 치르면 다시 켜진다
- [ ] 설정 탭 "선수 이름"에서 바꾸면 홈과 중계에 새 이름이 나온다

### 12. 배속과 바로 경기

- [ ] 경기 중에 경기 탭 맨 위에 배속 카드(1× 2× 4× 8×)가 나온다
- [ ] 8×로 바꾸면 문자 중계가 눈에 띄게 빨라지고, 1×로 돌리면 다시 느려진다
- [ ] 8×에서도 이닝 교대·득점 장면이 순서대로 다 나오고 한 경기가 2분쯤에 끝난다
- [ ] 고른 배속이 다음 경기와 앱을 껐다 켠 뒤에도 남아 있다
- [ ] 경기 기회가 없을 때 다음 경기 카드에 "바로 경기 · ₩300만"(선수 모드는 "3.0M P")이 나온다
- [ ] 누르면 자금(포인트)이 줄고 곧바로 경기가 시작된다
- [ ] 그 경기가 끝난 뒤 버튼의 값이 두 배가 되어 있다
- [ ] 한 시간이 지나 경기 기회가 저절로 생긴 뒤에는 값이 처음으로 돌아가 있다
- [ ] 자금(포인트)이 모자라면 버튼이 꺼지고, 마우스를 올리면 이유가 나온다
- [ ] 경기 중 배속 카드에 "결과 바로 보기 · ₩100만"(선수 모드는 "1.0M P")이 나온다
- [ ] 누르면 곧바로 경기 결과가 나오고, 자금(포인트)이 그만큼 줄고, 알림이 한 번 온다
- [ ] 포인트가 모자라면 버튼이 꺼지고, 마우스를 올리면 이유가 나온다
- [ ] 선수 모드 홈·훈련 탭의 훈련 포인트가 "12.3M P"처럼 K·M으로 나온다

### 13. 한 줄 설치와 구단 모드 숨기기

설치 명령은 진짜 응용 프로그램 폴더에 앱을 넣는다. 시험 삼아 돌릴 때는 `TOKEN_SPORT_HOME=임시 폴더/src TOKEN_SPORT_APP_DIR=임시 폴더/apps TOKEN_SPORT_NO_OPEN=1`을 앞에 붙이면 그 폴더에만 설치하고 앱을 열지 않는다.

- [ ] 처음 설치: 한 줄 명령을 실행하면 응용 프로그램 폴더에 Token Sports가 생기고 상단바에 아이콘이 뜬다
- [ ] 예전 이름(Token Baseball)으로 설치된 맥에서 설치 명령을 다시 실행하면 예전 앱이 사라지고 Token Sports만 남는다. 선수 저장과 알림 권한은 그대로다
- [ ] 다시 실행(업데이트): 실행 중인 앱이 꺼지고 새 앱이 열리며, 하던 선수가 그대로다
- [ ] 설정 탭 "업데이트" 카드의 명령이 `~/.token-sport/Scripts/install.sh`로 나온다
- [ ] `--uninstall`: 앱과 `~/.token-sport`가 지워지고 저장 파일은 남는다
- [ ] 배포 파일이 올라온 뒤: 설치 명령이 "배포 파일을 내려받는 중"으로 시작하고 몇 초 만에 끝난다. Xcode가 없는 맥에서도 된다
- [ ] 받은 `.dmg`를 다른 맥에서 더블클릭했을 때 "확인되지 않은 개발자" 경고 없이 열린다
- [ ] 배포 파일로 설치한 앱의 설정 탭 "업데이트" 카드에 버전 번호(예: 지금 0.2.0)가 나온다
- [ ] 처음 화면에 야구 선수, 축구 선수, 농구 선수 세 가지가 나온다

### 스카우트

화면 그림으로 생김새는 확인했지만, 직접 눌러 보지는 못했다.

- [ ] 경기를 몇 번 치르면 경기 결과에 "○○의 스카우트가 지켜보기 시작했습니다"가 나오고, 커리어 탭 "스카우트" 카드에 그 구단과 관심도가 나온다
- [ ] 경기 뒤 관심도 옆의 ▲▼ 숫자가 평점에 따라 바뀐다
- [ ] "다음 경기에 ○○ 스카우트가 직접 보러 옵니다"가 홈 탭과 스카우트 카드에 나오고, 그 경기 결과에 스카우트의 평가 한 줄이 나온다
- [ ] 관심도가 70을 넘으면 "제안을 준비하고 있습니다"(이적 기간) 또는 "이적 기간이 열리면 제안합니다"가 나오고, 이적 기간에 그 구단의 제안이 온다
- [ ] 제안을 거절하면 그 구단이 스카우트 카드에서 사라진다
- [ ] 이적 요청을 누르면 관심도가 오르고 안내문의 문턱이 50으로 바뀐다
- [ ] 구단을 옮기면 스카우트 카드가 빈다
- [ ] 예전 저장 파일(스카우트가 없던 때)로 켜도 그대로 이어지고, 경기를 치르면 스카우트가 생긴다

### 농구 선수

화면 그림으로 생김새는 확인했지만, 직접 눌러 보지는 못했다.

- [ ] "농구 선수" 카드를 고르면 선수 만들기에 다섯 포지션과 시작 포인트가 나온다. 포지션을 바꾸면 포인트 줄이 그 포지션의 능력치로 바뀐다
- [ ] 만든 뒤 홈 탭에 "다음 경기는 벤치에서 시작합니다. 15분쯤 뜁니다" 같은 안내가 나온다
- [ ] 경기를 시작하면 쿼터별 점수와 팀 기록이 움직이고, 1배속으로 15분쯤 걸린다. 득점마다 멈추지 않는다
- [ ] 경기 중 상단바에 농구공과 점수, "3Q 4:12" 같은 시간이 나온다. 득점 알림은 오지 않고 경기 종료 알림만 온다
- [ ] 경기 뒤 평점과 "17분 13점 2리바운드" 같은 기록, "이번 경기 성장"이 나온다
- [ ] 경기 탭에서 플레이 스타일을 바꿀 수 있다
- [ ] 리그 탭 순위표가 승률로 나오고, 기록 순위에 득점·리바운드·어시스트가 나온다
- [ ] 경기 도중에 앱을 껐다 켜도 중계가 이어진다
- [ ] 야구·축구 선수 저장은 그대로 남아 있고, 설정 탭에서 오갈 수 있다
- [ ] 설정 탭 → 모드에 야구 선수·축구 선수만 나온다 (구단 경영 스위치가 없다)
- [ ] 설정 탭에서 다른 모드로 바꾸면 곧바로 그 모드의 홈 탭이 나온다
- [ ] 구단을 하던 중에 끄더라도 그 구단은 그대로 할 수 있다

## 시간이 오래 걸리는 것

실시간으로는 한 시즌에 여드레쯤 걸려서 직접 보기 어렵다. 자동 테스트로는 지나가는 것을 확인했고, 화면은 보지 못했다.

- [ ] 정규시즌이 끝날 때 시즌 목표 달성 여부가 소식에 나온다
- [ ] 수상하면 커리어 탭 "통산"에 남는다
- [ ] 소속 구단이 승격하거나 강등되면 다음 시즌을 그 리그에서 뛴다
- [ ] 야구: 2위나 3위로 마치면 승격 와일드카드, 이기면 윗 리그 9위와 승강 플레이오프를 치른다
- [ ] 축구: 1위나 2위로 마치면 바로 승격한다. 3~6위로 마치면 준결승 1차전(원정 또는 홈) → 2차전 → 결승 순으로 치른다. 2차전에서 합산이 같으면 연장으로 간다
- [ ] 시즌이 바뀌면 커리어 탭에 시즌별 기록이 한 줄 늘어난다
- [ ] "은퇴" 버튼이 늘 보이고, 첫 시즌 도중에는 꺼져 있으며 아래에 이유가 나온다. 한 시즌을 마친 오프시즌에 켜진다
- [ ] 은퇴 뒤 커리어 탭(새 선수를 만든 뒤)의 "명예의 전당"에 은퇴한 선수가 칭호와 함께 나오고, 누르면 기록이 펼쳐진다
- [ ] 은퇴하면 기록 화면이 나오고, 새 선수를 만들면 같은 세계에서 다시 시작한다

빨리 보려면 테스트 코드의 `CareerAuto`(`Tests/TokenBaseballCoreTests/CareerTestSupport.swift`)로 저장 파일을 원하는 시점까지 돌려 만든 뒤 그 파일로 앱을 띄운다. 화면 그림만 필요하면 다음으로 뽑는다. [플레이 가이드](guide/README.md)의 그림도 이렇게 만들었다.

```sh
TOKEN_BASEBALL_SAVE=/tmp/tb-test/save.json TOKEN_BASEBALL_SNAPSHOT=/tmp/tb-snap swift run TokenBaseball
```

## 재미와 속도 (정답이 없는 것)

며칠 해 보고 판단할 것들이다. 수치는 `Sources/TokenBaseballCore/Career/Balance+Career.swift`에 모여 있다.

- [ ] 성장 속도: 평소 쓰는 토큰 양으로 한 시즌에 능력이 얼마나 오르는가. 너무 빠르거나 느리면 훈련 횟수(경기 사이 5번)와 비용을 고친다
- [ ] 훈련 비용: 포인트가 계속 남는가, 계속 모자란가
- [ ] 리그 한도를 없앤 뒤: 포인트가 많으면 아랫 리그에서 너무 빨리 크지 않는가
- [ ] 축구 주전 경쟁: 교체로만 나오는 기간이 너무 길지 않은가
- [ ] 야구 경기: 점수와 홈런 수가 자연스러운가 (팀당 4점 안팎, 홈런 1개 안팎)
- [ ] 선발 투수: 나오지 않는 경기를 지켜보는 것이 지루한가
- [ ] 감독 신뢰: 너무 쉽게 100이 되거나 0이 되지 않는가
- [ ] 이적 제안: 너무 자주 오거나 너무 안 오지 않는가
- [ ] 평점: 잘한 경기와 못한 경기가 평점으로 납득이 되는가
