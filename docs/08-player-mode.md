# 8. 축구 선수 모드

구단을 운영하는 대신 **축구 선수 한 명**이 되어 커리어를 보내는 모드다. 만들어져 있다.

여기에는 축구 선수 모드의 규칙을 적는다. 훈련 포인트, 계약, 이적, 은퇴의 틀은 [야구 선수 모드](09-baseball-player-mode.md)와 같아서, 같은 부분은 짧게 적고 그 문서로 연결한다. 여기 없는 내용(6부 리그와 승강, 축구 규칙과 경기 엔진, 능력과 잠재력, 세계 시뮬레이션)은 1~7번 문서를 따른다.

화면을 보며 따라 하려면 → [축구 개인 성장 가이드](guide/football-player.md)

## 한 줄 소개

✅ 내가 축구 선수가 된다.

16세에 6부 시민 구단에 입단해, 코딩하며 쓴 토큰으로 훈련하고, 주전을 따내고, 더 높은 리그의 구단으로 옮겨 가며 1부 프로 리그의 스타가 되는 것이 목표다.

| | 구단 모드 | 선수 모드 |
|---|---|---|
| 내가 되는 것 | 구단주 겸 단장 | 선수 한 명 |
| 토큰 | 구단 자금 | 훈련 포인트 |
| 키우는 것 | 구단 (시설, 선수단, 인지도) | 내 선수 (능력치, 감독 신뢰, 명성) |
| 올라가는 길 | 구단이 승격한다 | 구단이 승격하거나, 내가 윗 리그 구단으로 옮긴다 |
| 경기 전에 정하는 것 | 포메이션, 전술, 선발 11명 | 플레이 스타일 |
| 실패 | 파산 | 없음 (방출돼도 다른 구단을 찾는다) |
| 끝 | 없음 | 은퇴 |

## 핵심 루프

```
코딩한다 (토큰 사용)
   ↓
훈련 포인트가 쌓인다
   ↓
훈련한다: 훈련을 골라 능력을 올린다 (경기 사이에 다섯 번)
   ↓
1시간마다 경기에 나선다 (선발 / 교체는 감독이 정한다)
   ↓
경기 평점이 나온다
   ↓
평점이 쌓이면 감독 신뢰와 명성이 오른다
   ↓
주전이 되고, 더 큰 구단에서 제안이 온다
```

## 시작

| 고르는 것 | 내용 |
|---|---|
| 이름 | 직접 입력 |
| 포지션 | 골키퍼 / 수비수 / 미드필더 / 공격수. 커리어 중에는 바꿀 수 없다 |
| 출신 | 도시를 고른다 (선수 소개에만 쓴다) |
| 시작 포인트 | 5개를 내 포지션의 능력치에 나눠 넣는다 (하나에 2개까지) |

정해져 있는 것:

- **나이 16세**로 시작한다.
- 6부 시민 아마추어 리그의 중위권 구단(스무 구단 중 가운데)에 입단한다. 같은 포지션에서 가장 약한 선수의 자리를 넘겨받으므로 구단의 포지션별 인원은 그대로다.
- **타고난 재능**: 선수마다 다르다. 만들 때 난수로 정해진다.
  - **타고난 능력**: 15~30 사이. 시작 포인트는 이 위에 더해진다.
  - **잠재력(성장 한계)**: 68~95 사이. 숫자는 숨겨져 있고, 입단할 때 스카우트 평가(소식)와 홈 탭의 선수 카드에 **재능 등급**으로만 나온다: 천재(90 이상) · 특급 유망주(84 이상) · 유망주(77 이상) · 평범(71 이상) · 노력파(그 아래).
- **시작 포인트 5개**: 만들 때 내 포지션의 능력치에 직접 나눠 넣는다. 포인트 하나에 그 능력치가 +3 오르고, 능력치 하나에는 2개까지 넣는다 (비중이 큰 능력치 하나에 몰아넣으면 포지션마다 시작 능력이 크게 벌어져서 막았다. 가장 좋게 넣으면 능력 +3.5 ~ +5.4). 넣지 않은 포인트는 사라진다.
- 세계는 구단 모드와 똑같이 만든다. **6개 리그, 리그마다 20개 구단**이 모두 CPU 구단이다. 한 시즌은 **38라운드**다 (모든 팀과 홈 한 번, 원정 한 번).
- 리그가 10팀(36라운드)이던 때 만든 저장 파일은 그대로 이어진다. 하던 시즌은 10팀으로 끝까지 치르고, **다음 시즌이 시작될 때 리그마다 새 구단 열 곳이 합류**해 20팀 38라운드가 된다 (소식에 "리그 확장"이 뜬다).

기획 때 있던 "연고지를 골라 그 도시의 구단에 입단"과 "등번호"는 넣지 않았다. 입단 구단은 정해진다.

## 토큰 → 훈련 포인트

✅ 토큰 수를 가중치 없이 그대로 쓴다. 선수를 만든 뒤에 쓴 토큰만 세고, 시작할 때 100,000 포인트를 갖고 있다.

### 훈련

훈련 탭에서 훈련을 고른다. **어떤 훈련이든 능력(CA)이 같은 양만큼 오른다.** 포지션에서 덜 중요한 능력치일수록 한 번에 많이 오른다 (능력치 증가 = 리그별 훈련 효과 ÷ 그 능력치의 비중). 리그별 훈련 효과(6부 0.025 → 1부 0.05)와 비용 배수(0.5배 → 1.4배)는 [야구 선수 모드](09-baseball-player-mode.md#훈련)의 표와 같다.

| 훈련 | 오르는 능력치 | 훈련할 수 있는 포지션 |
|---|---|---|
| 슈팅 연습 | 슈팅 | 공격수, 미드필더 |
| 패스 훈련 | 패스 | 모두 |
| 드리블 훈련 | 드리블 | 공격수, 미드필더 |
| 수비 훈련 | 수비 | 수비수, 미드필더 |
| 스프린트 | 스피드 | 모두 |
| 웨이트 트레이닝 | 피지컬 | 골키퍼, 수비수, 공격수 |
| 골키핑 훈련 | 골키핑 | 골키퍼 |
| 러닝 | 체력 | 수비수, 미드필더, 공격수 |

포지션별 능력 비중 (괄호 안은 훈련 한 번에 그 능력치가 오르는 양, 6부~1부):

| 포지션 | 비중 |
|---|---|
| 골키퍼 | 골키핑 70% (+0.04~0.07) · 피지컬 15% (+0.17~0.33) · 패스 10% (+0.25~0.50) · 스피드 5% (+0.50~1.00) |
| 수비수 | 수비 40% (+0.06~0.12) · 피지컬 20% (+0.12~0.25) · 스피드 15% (+0.17~0.33) · 패스 15% (+0.17~0.33) · 체력 10% (+0.25~0.50) |
| 미드필더 | 패스 35% (+0.07~0.14) · 드리블 20% (+0.12~0.25) · 수비 15% (+0.17~0.33) · 체력 15% (+0.17~0.33) · 슈팅 10% (+0.25~0.50) · 스피드 5% (+0.50~1.00) |
| 공격수 | 슈팅 38% (+0.07~0.13) · 드리블 20% (+0.12~0.25) · 스피드 17% (+0.15~0.29) · 피지컬 10% (+0.25~0.50) · 패스 8% (+0.31~0.62) · 체력 7% (+0.36~0.71) |

능력은 어느 훈련으로나 똑같이 오르므로, **무엇을 올릴지는 경기에서 무엇을 하고 싶은지로 고른다.** 슈팅이 높으면 골이, 패스가 높으면 도움이, 수비가 높으면 공을 뺏는 장면이, 체력이 높으면 뛰는 시간이 늘어난다.

**비용**은 그 능력치의 지금 값으로 정해지고, 훈련할 때마다 조금씩 오른다 (25에서 12.5만, 50에서 58만, 70에서 199만, 85에서 500만 포인트). 설정의 가격 난이도(10%~200%)가 적용된다.

**제한**

1. **훈련 횟수**: 경기와 경기 사이에 다섯 번.
   - **추가 훈련** (설정 탭에서 켠다, 기본은 꺼짐): 다섯 번을 넘겨서도 훈련할 수 있다. 한 번마다 비용이 1.5배씩 더 든다 (1.5배, 2.25배, 3.4배…). 한계 돌파 훈련도 같이 비싸진다. 다음 경기를 치르면 처음 값으로 돌아간다.
   - **크리티컬**: 훈련마다 1% 확률로 세 배 오른다 (포인트는 그대로, 한계와 99는 넘지 못한다).
2. **잠재력**: 능력은 잠재력을 넘지 못한다. 남은 여유가 10 이하면 비용이 2배다.
3. **리그 한도는 없다**: 예전에는 지금 리그 수준 +5까지만 올랐지만 없앴다. 어느 리그에서든 타고난 한계(잠재력)까지 훈련할 수 있다.
4. **나이**: 필드 선수는 29세, 골키퍼는 32세부터 훈련으로 올릴 수 없다.

- 훈련하지 않아도 경기를 뛰면 조금씩 큰다 (구단 모드 성장의 15%. 16세 선발이면 한 경기에 능력 +0.1쯤으로 6부의 훈련 네 번과 비슷하고, 나이가 들거나 한계에 가까워지면 줄어든다). 경기 결과에 "이번 경기 성장: 능력 +0.10"처럼 적힌다.
- **한계 돌파 훈련**: 1,500만 포인트로 잠재력을 +1 넓힌다.

## 경기

✅ 경기 기회(1시간에 하나, 최대 3개), 직접 눌러 시작, 약 15분의 실시간 중계와 배속은 구단 모드와 같다. 경기 기회가 없을 때 훈련 포인트로 사서 바로 치를 수도 있다 → [경기](02-match.md#토큰으로-바로-경기). 기다리기 싫으면 100만 포인트로 [결과 바로 보기](02-match.md#결과-바로-보기)를 쓴다. 내 구단의 경기가 통째로 중계된다.

- 스코어보드 아래에 **내 선수 줄**이 생긴다: 지금까지의 평점, 뛴 시간, 골·도움·슈팅, 수비 횟수. 벤치에 있으면 "벤치에서 대기 중".
- 내 선수가 나온 장면은 문자 중계에서 강조된다.

### 출전: 주전 경쟁

감독은 같은 포지션 선수들의 능력을 비교해 선발을 정한다. 포메이션에서 내 포지션이 서는 자리 수만큼이 선발이다 (예: 4-4-2의 공격수는 2명, 4-3-3은 3명).

| 출전 | 조건 |
|---|---|
| **선발** | `내 능력 + 감독 신뢰 보정`이 내 포지션의 선발 자리 안에 든다. 보정은 신뢰 50을 기준으로 −5 ~ +5 |
| **교체 투입** | 선발이 아니면 벤치에서 시작해 **반드시** 교체로 들어간다. 감독 신뢰가 높을수록 일찍 들어간다 |
| **골키퍼** | 교체로 나올 수 없다. 주전이 아니면 친선 경기와 **네 경기 중 한 경기**에 선발로 나온다 |
| **출장 정지** | 퇴장하면 다음 리그 한 경기, 시즌 경고 다섯 장마다 한 경기를 쉰다 |

교체로 들어가는 시간:

| 감독 신뢰 | 0 | 20 | 40 | 60 | 80 이상 |
|---|---|---|---|---|---|
| 들어가는 시간 | 85분 | 80분 | 70분 | 60분 | 50분 |

같은 자리에서 가장 지친 선수와 바뀐다.

"선발이 아니어도 반드시 교체로 나온다"는 현실적이지는 않다. 한 시간에 한 번 15분을 보는 게임에서 내가 한 번도 나오지 않는 경기는 재미가 없어서 이렇게 했다.

### 경기 전에 정하는 것: 플레이 스타일

✅ 경기 중에는 개입하지 않는다. 포메이션, 전술, 선발 11명은 감독이 정한다.

경기 전에 플레이 스타일을 하나 고른다 (골키퍼는 없다).

| 스타일 | 슈팅을 가져갈 가능성 | 도움을 줄 가능성 | 공을 뺏고 걷어내는 장면 | 그 밖에 |
|---|---|---|---|---|
| 균형 | ×1 | ×1 | ×1 | |
| 욕심내기 | ×1.7 | ×0.55 | ×0.6 | 무리한 슈팅이 섞여 내 슈팅의 정확도가 떨어진다 |
| 연계 | ×0.65 | ×1.7 | ×1 | 도움 하나의 평점이 0.6 → 0.8 |
| 수비 가담 | ×0.75 | ×0.9 | ×2 | 체력이 1.2배 빨리 준다 |

### 경기 평점

1.0~10.0이고 6.0이 "무난했다"이다.

```
평점 = 6.0 + (한 일 − 못한 일 + 팀 결과 + 포지션 보정) × 뛴 시간 보정
```

| 한 일 | | 못한 일 | |
|---|---|---|---|
| 골 | +1.0 | 반칙 | −0.1 |
| 도움 | +0.6 (연계 스타일 +0.8) | 경고 | −0.3 |
| 유효 슈팅 | +0.15 | 퇴장 | −1.5 |
| 전진 (우리 진영 → 중원, 중원 → 상대 진영) | +0.05 | 실점 (골키퍼) | −0.77 |
| 공 뺏기 | +0.12 | | |
| 걷어내기·슈팅 막기 | +0.12 | | |
| 선방 (골키퍼) | +0.43 | | |
| 무실점 (골키퍼, 60분 이상 뛰었을 때) | +0.8 | | |
| 무실점 (수비수, 60분 이상 뛰었을 때) | +0.5 | | |

- **팀 결과**: 이기면 +0.2, 지면 −0.2.
- **포지션 보정**: 포지션마다 기록이 쌓이는 양이 달라 맞춘다 (골키퍼 +0.45, 수비수 0, 미드필더 −0.1, 공격수 +0.2).
- 골키퍼는 **막아 낸 골**로 평가한다. 실력이 비슷한 골키퍼라면 유효 슈팅의 36%가 들어가므로, 선방 하나는 0.36골, 실점 하나는 −0.64골로 치고 한 골에 1.2를 곱한다 (그래서 선방 +0.43, 실점 −0.77). 약한 팀에서 선방이 많아도 실점이 같은 비율로 따라오면 평점이 오르지 않고, 잘 막는 골키퍼는 매 경기 꾸준히 오른다. 무실점은 팀이 강해 슈팅을 받지 않은 날의 몫으로 +0.8을 준다.
- 공을 뺏거나 걷어내거나 전진하는 장면, 슛과 도움은 그 능력치가 높은 선수에게 더 자주 간다. 슈팅 90인 공격수는 슈팅 25인 동료보다 3.8배 자주 슛을 맡는다 → [능력 차이가 기록으로 나타나는 정도](12-how-it-works.md#84-그러면-훈련은-어디에-나타나는가).
- **뛴 시간 보정**: `0.35 + 뛴 시간 ÷ 90 × 0.65` (최대 1). 10분 뛰고 9.0이 나오지 않게, 짧게 뛰면 6.0 쪽으로 당겨진다.
- 공을 뺏거나 걷어내거나 전진하는 장면은 그 자리 선수 가운데 **그 능력치가 좋은 선수**가 더 자주 맡는다. 수비와 패스를 훈련한 만큼 평점에 돌아온다.

### 감독 신뢰와 명성

| | 오르는 때 | 내리는 때 |
|---|---|---|
| **감독 신뢰** (40에서 시작) | 평점 7.0 이상 (최대 +6), 시즌 목표 달성 (+10), 훈련 (+0.1) | 평점 6.0 미만 (최대 −6), 시즌 목표 실패 (−5), 이적 요청 (−10) |
| **명성** | 평점 6.3을 넘긴 경기, 수상 (+8), 시즌 목표 달성 (+3) | 시즌이 바뀔 때 10% |

- **30분도 못 뛴 경기**는 평점이 6점 근처에 몰리므로 기준이 다르다: 6.5 이상이면 신뢰 +0.5, 5.7 미만이면 −0.5.
- 친선 경기는 신뢰가 절반만 움직이고 명성은 오르지 않는다.
- 구단을 옮기면 신뢰는 40에서 다시 시작한다.
- 명성은 리그마다 오를 수 있는 한도가 있다 (6부 20 → 1부 100).

### 컵대회

리그와 별개로, 여섯 리그 120개 구단이 모두 나오는 **단판 승부** 대회가 시즌마다 열린다. 6부 구단도 1부 구단과 만날 수 있다.

| 라운드 | 1라운드 | 64강 | 32강 | 16강 | 8강 | 준결승 | 결승 |
|---|---|---|---|---|---|---|---|
| 열리는 때 (리그를 이만큼 치른 뒤) | 3라운드 | 8라운드 | 13라운드 | 18라운드 | 23라운드 | 29라운드 | 35라운드 |
| 경기 수 | 56 | 32 | 16 | 8 | 4 | 2 | 1 |

(야구는 60개 구단이 여섯 라운드를 치른다 → [야구 선수 모드](09-baseball-player-mode.md). 농구도 60개 구단, 여섯 라운드 → [농구 선수 모드](11-basketball.md).)

- **대진**: 1부에서 가장 강한 여덟 팀은 1라운드를 쉰다. 그 뒤로는 매 라운드 다시 추첨하고, **아랫 리그 구단이 홈**에서 치른다.
- **승부**: 반드시 승자가 나온다. 야구는 연장을 끝까지 하고 콜드게임이 없다. 축구는 연장과 승부차기까지 간다.
- **일정**: 때가 되면 "다음 경기"가 리그 경기 대신 컵 경기로 바뀐다. 경기 기회를 하나 쓰고, 리그 라운드는 넘어가지 않는다. 내 구단이 떨어졌거나 쉬는 라운드면 저절로 진행된다.
- **보상 (내 선수)**: 이겨서 올라가면 명성 +1. **윗 리그 구단을 잡으면 리그 차이 하나마다 +2**가 더 붙는다 (6부가 4부를 잡으면 +5). 우승하면 명성 +12와 감독 신뢰 +5, 수상 경력에 남는다. 준우승은 명성 +5. 평점에 따른 감독 신뢰와 명성, 라이벌 맞대결은 리그 경기와 같이 반영된다.
- 컵 경기는 리그 순위와 시즌 기록(타율, 골 수 등), 평균 평점에 들어가지 않는다.
- 리그 탭의 "컵대회" 카드에서 내 구단이 걸어온 길과, 8강부터는 전체 대진을 본다.

### 컨디션, 기세, 연속 기록

- **컨디션**: 경기가 끝나면 다음 경기의 컨디션이 정해진다. 홈 탭의 선수 카드에서 경기 전에 볼 수 있다. 그 경기에서만 내 능력치에 곱해지고, 선수의 실제 능력치는 바뀌지 않는다.

  | 컨디션 | 최상 | 좋음 | 보통 | 나쁨 | 최악 |
  |---|---|---|---|---|---|
  | 능력치 | +6% | +3% | 그대로 | −3% | −6% |
  | 나올 비율 | 10% | 25% | 40% | 20% | 5% |

- **기세**: 평점 7.0 이상인 경기가 세 번 이어지면 기세가 붙어 능력치가 2% 오르고, 경기로 얻는 명성이 1.25배가 된다. 평점 5.5 이하가 세 번 이어지면 슬럼프로 2% 내린다. 그 사이의 평점이 한 번 나오면 끊긴다. 친선 경기는 세지 않는다.
- **연속 기록**: 타자는 연속 안타, 투수는 연속 무자책, 축구 필드 선수는 연속 공격포인트(골·도움), 골키퍼는 연속 무실점 경기를 센다. 개인 최고 기록이 남는다.

### 라이벌

같은 리그의 다른 구단에서 나와 역할이 같고 능력이 비슷한(조금 높은) 또래 선수 한 명이 라이벌이 된다. 커리어 탭의 "라이벌" 카드에서 그 선수의 능력과 내 능력, 이번 시즌 기록을 나란히 본다.

- **맞대결**: 라이벌의 구단과 만나 둘 다 뛴 날, 평점이 높은 쪽이 이긴다. 이기면 명성이 1 오른다. 전적이 카드에 남는다.
- 리그가 달라지거나(이적, 승격, 강등), 새 시즌에 내가 능력 5 넘게 앞서 있으면 새 라이벌이 생긴다.

### 토큰으로 치른 경기의 실전 경험

경기 기회가 없을 때 훈련 포인트로 사서 치른 경기("바로 경기")에서는 **능력이 조금 오른다.** 평점이 좋을수록 많이 오른다: `0.02 + (평점 − 6) × 0.03`, 가장 적게 0.02, 가장 많이 0.1. 포지션의 능력치가 고르게 오르고, 한계(잠재력)는 넘지 못한다. 출전하지 않은 날은 오르지 않는다.

### 명성 활동

커리어 탭의 "명성 활동" 카드에서 훈련 포인트를 들여 명성을 직접 올린다. 경기에서 잘해야만 오르던 명성을 포인트로도 쌓을 수 있다.

| 활동 | 포인트 | 명성 (0일 때) | 그 밖에 |
|---|---|---|---|
| 팬 사인회 | 150만 P | +1.0 | |
| 지역 방송 인터뷰 | 400만 P | +2.5 | |
| 유소년 교실 봉사 | 800만 P | +4.0 | 감독 신뢰 +1 |

- **경기 사이에 한 번**만 한다. 훈련 횟수와는 따로 센다.
- 명성이 지금 리그의 한도에 가까울수록 덜 오르고, 한도에 닿으면 할 수 없다. 버튼에 지금 실제로 오르는 양이 적혀 있다.
- 무소속일 때는 할 수 없다. 포인트는 가격 난이도에 따라 달라진다.

### 이름 바꾸기

설정 탭의 "선수 이름"에서 바꾼다 (12자까지). 지난 시즌 기록과 구단 이력은 그대로다.

### 시즌 목표

| 포지션 | 목표 |
|---|---|
| 공격수 | 골 (6골 안팎, 리그 수준과 내 능력에 따라 3~12골) |
| 미드필더 | 공격 포인트 (골 + 도움, 3~12개) |
| 수비수 | 24경기 출전 |
| 골키퍼 | 10경기 출전 |

채우면 감독 신뢰 +10과 명성 +3, 채우지 못하면 감독 신뢰 −5.

## 계약, 이적, 은퇴

[야구 선수 모드](09-baseball-player-mode.md#구단과의-관계)와 같다. 축구에서 다른 것만 적는다.

- **이적 기간**: 여름(오프시즌과 개막 뒤 세 라운드)과 겨울(17~20라운드). 이 기간에만 이적 제안이 온다.
- **연봉**: 계약 기간 동안 그대로다. 재계약하거나 구단을 옮길 때, 구단이 승격할 때 오른다.
- **예상 입지**: 제안한 구단의 포메이션에서 내 포지션 선발 자리 수와 그 구단 선수들의 능력으로 정해진다. "주전"이면 가자마자 선발이고, "유망주"면 교체로 시작한다.
- 이적 제안은 나를 지켜보던 구단에서, 관심도가 쌓였을 때 온다 → [스카우트](09-baseball-player-mode.md#스카우트). 규칙은 종목과 상관없이 같다.
- 스카우트는 두 리그 위까지만 본다. 유망주로 데려가는 것은 바로 위 리그만이고, 23세 이하에 명성이 리그 한도의 80% 이상, 능력이 그 리그 최저 수준 −8 이상일 때다.

## 기획과 달라진 것

처음 기획(이 문서의 예전 판)에서 바뀐 것을 적어 둔다.

| 기획 | 만든 것 | 이유 |
|---|---|---|
| 경기 사이 훈련 세 번, 한 번에 능력치 +1 | 다섯 번, 한 번에 능력 +0.025~0.05 (리그별) | 시뮬레이션에서 한 시즌 만에 6부를 벗어났고, 골키퍼가 다른 포지션보다 1.5배 빨리 컸다 |
| 31세부터 훈련 불가 | 필드 선수 29세, 골키퍼 32세 | 축구의 전성기에 맞췄다 |
| 연고지를 골라 그 도시의 구단에 입단, 등번호 | 구단은 정해진다, 등번호 없음 | 줄였다 |
| 공을 뺏김 −0.1, 페널티킥 실축 −0.5, 결승골 +0.3 | 없음 | 엔진이 그 기록을 선수별로 남기지 않는다 |
| 특성을 커리어 중에 얻기 | 없음 | 다음에 |
| 내 구단이 없는 세계로 코드를 크게 바꾼다 | "내 선수가 뛰는 CPU 구단"을 따라가는 방식 | 구단 모드의 코드를 거의 그대로 쓸 수 있었다 |
