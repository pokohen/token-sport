# 3. 리그

## 리그 구조

✅ 6부제다. 내 팀은 6부 시민 아마추어에서 시작한다.

| 부 | 리그 | 성격 |
|---|---|---|
| 1부 | **프로** | 최상위. KBO 1군 수준 |
| 2부 | **세미프로** | 퓨처스 리그 수준 |
| 3부 | **아마추어** | 실업·대학 야구 수준 |
| 4부 | **시민 프로** | 시민 리그 최상위 |
| 5부 | **시민 세미프로** | |
| 6부 | **시민 아마추어** | 시작 리그. 동네 사회인 야구 수준 |

💡 야구는 리그마다 10팀 (KBO와 같은 수), 축구는 리그마다 **20팀** (잉글랜드 1부와 같은 수), 농구는 야구와 같은 10팀.

✅ CPU 팀은 리그별 강도 범위 안에서 내 팀 수준에 적당히 맞춰 준다. 리그가 올라갈수록 범위가 높아진다 (예: 6부 20~40 → 1부 70~92). 자세한 내용은 → [세계 시뮬레이션](06-world-simulation.md#cpu-팀-맞춰주기)

✅ 6개 리그가 모두 같은 속도로 진행된다. 내가 경기를 한 번 하면 모든 리그가 한 라운드씩 진행된다.

## 일정

✅ 야구는 같은 리그의 모든 팀과 홈 2경기, 원정 2경기씩 치른다. 축구는 홈 1경기, 원정 1경기씩 치른다.

- 야구: 10팀이면 상대 9팀 × 4경기 = **팀당 36경기**, 한 시즌은 **36라운드**.
- 축구: 20팀이면 상대 19팀 × 2경기 = **팀당 38경기**, 한 시즌은 **38라운드**.
- 농구: 야구와 같다. 10팀, **36라운드**.
- 리그가 10팀이던 때 만든 축구 저장 파일은 하던 시즌을 10팀 36라운드로 끝까지 치르고, 다음 시즌이 시작될 때 리그마다 새 구단 열 곳이 합류한다.
- 💡 야구 일정은 더블 라운드 로빈 2번으로 만든다. 1~18라운드에서 모든 팀과 홈 1번·원정 1번, 19~36라운드에서 한 번 더. 축구는 더블 라운드 로빈 1번이다 (1~19라운드와 20~38라운드가 홈·원정만 바뀐 같은 대진).
- 💡 같은 상대와 연속으로 붙지 않게 섞는다.

## 순위

| 종목 | 순서 |
|---|---|
| 야구, 농구 | 승률(무승부 제외) → 동률 팀끼리의 상대 전적 → 다득점 |
| 축구 | 승점(승 3, 무 1, 패 0) → 골득실 → 다득점 → 동률 팀끼리의 상대 전적 |

## 승강

✅ 승격과 강등은 반드시 있다. 정규시즌이 모두 끝난 뒤 순위로 정한다.

방식은 종목마다 다르다. 실제 야구에는 승강제가 없어 **야구는 직접 만든 방식**이고, **축구는 잉글랜드 리그 방식**을 따른다. **농구는 야구 방식**을 그대로 쓴다. 두 방식 모두 전문가 검토를 거쳐 고쳤다 → [야구 검토](review/baseball.md#승강), [축구 검토](review/football.md#승강).

### 한눈에 보기

| | 야구 (농구도 같음) | 축구 |
|---|---|---|
| 한 경계에서 오르내리는 팀 | 1~2팀 | **3팀** |
| 자동 승격 | 하위 리그 1위 | 하위 리그 **1·2위** |
| 자동 강등 | 상위 리그 10위 | 상위 리그 **맨 아래 세 팀 (18~20위)** |
| 플레이오프에 나가는 팀 | 하위 2위·3위, 상위 9위 | 하위 **3~6위** |
| 상·하위 리그 팀이 맞붙는가 | 맞붙는다 (승강 플레이오프) | 맞붙지 않는다 |
| 내 구단의 승격 조건 | 시즌 중 **신청** + 인지도 + 신청비 | **구장 등급** (경기장 레벨). 신청 없음 |

### 야구: 와일드카드와 승강 플레이오프

```
하위 리그 1위 ──────────────────────────────▶ 자동 승격
하위 리그 2위 ─┐
               ├─ 승격 와일드카드 ─ 승자 ─┐
하위 리그 3위 ─┘                          ├─ 승강 플레이오프 (3전 2선승) ─▶ 이긴 팀이 윗 리그
상위 리그 9위 ────────────────────────────┘
상위 리그 10위 ─────────────────────────────▶ 자동 강등
```

| 단계 | 방식 |
|---|---|
| **승격 와일드카드** | 2위의 홈에서 치른다. 2위는 **한 번만 이기면** 되고, 3위는 **두 번 연속** 이겨야 한다 (최대 2경기) |
| **승강 플레이오프** | 와일드카드 승자 대 상위 9위. **3전 2선승**, 1·3차전은 상위 리그 팀의 홈. 승부가 날 때까지 연장한다 |

- 대진이 정해지면 두 팀 선발 투수의 휴식을 채워 준다. 1차전은 **에이스 대결**이 되고, 그 뒤로는 정규 휴식대로 2선발, 3선발이 나온다.
- 내 구단이 없는 대진은 화면 없이 바로 치른다.

**왜 이렇게 했나** (300시즌을 반복해 잰 값)

- 36경기 시즌에서 "실제로 가장 강한 팀"이 2위 안에 드는 비율은 1부 81%, 6부 66%다. 3위 안에 드는 비율은 95%와 84%다. 그래서 3위에게도 길을 열어 둔다.
- 시즌을 72경기로 늘려도 "실제 꼴찌가 10위를 하는" 비율은 47% → 57%로만 오른다. 그 대신 실시간은 두 배가 된다. 그래서 **36라운드를 유지한다**.
- 승강 플레이오프를 5전 3선승으로 늘려도 강팀이 이길 확률은 3~5%p만 오른다. 그래서 3전 2선승을 유지한다.

#### 신청 조건

✅ 내 구단이 승격하려면 시즌 중 **리그** 탭에서 신청해야 하고, 리그별 인지도 기준을 넘어야 한다.

| 현재 리그 → 목표 리그 | 필요 인지도 (💡) |
|---|---|
| 6부 시민 아마추어 → 5부 시민 세미프로 | 100 |
| 5부 → 4부 시민 프로 | 300 |
| 4부 → 3부 아마추어 | 700 |
| 3부 → 2부 세미프로 | 1,500 |
| 2부 → 1부 프로 | 3,000 |

- 신청 마감은 정규시즌 27라운드. 신청한 뒤에 인지도가 기준 아래로 떨어져도 신청은 유지된다.
- 신청비가 있다 (리그가 높을수록 비싸다).
- 신청하지 않으면 1~3위를 해도 승격할 수 없고, 그 자리는 다음 순위 팀이 이어받는다.
- AI 팀은 항상 신청한 것으로 본다.
- 승강제가 있는 실제 야구 리그(네덜란드, 독일)도 승격하려는 팀이 요건을 갖추고 의사를 밝혀야 했다. 그래서 신청 단계를 남겼다.

### 축구: 잉글랜드 방식

```
하위 리그 1위 ─────────────────────────────────────────▶ 자동 승격
하위 리그 2위 ─────────────────────────────────────────▶ 자동 승격
하위 리그 3위 ─┐
하위 리그 6위 ─┴─ 준결승 (두 경기 합산) ─┐
                                          ├─ 결승 (중립 구장 단판) ─▶ 이긴 팀 승격
하위 리그 4위 ─┬─ 준결승 (두 경기 합산) ─┘
하위 리그 5위 ─┘
상위 리그 18위 ────────────────────────────────────────▶ 자동 강등
상위 리그 19위 ────────────────────────────────────────▶ 자동 강등
상위 리그 20위 ────────────────────────────────────────▶ 자동 강등
```

| 단계 | 방식 |
|---|---|
| **준결승** | 3위 대 6위, 4위 대 5위. **홈·원정 두 경기 합산**. 1차전은 순위가 낮은 팀의 홈이고 90분에 끝난다 (비길 수 있다). 2차전은 순위가 높은 팀의 홈이고, 합산이 같으면 연장 → 승부차기. 원정 다득점 규칙은 없다 |
| **결승** | **중립 구장 단판** (홈 이점 없음). 비기면 연장 → 승부차기 |

- 잉글랜드의 챔피언십과 리그 원이 이 형식이다 (1~2위 자동 승격, 3~6위 플레이오프). 20팀 리그가 되면서 그대로 따른다: 한 경계에서 **세 팀**이 오르내린다. (리그가 10팀이던 때는 자동 승격 1팀, 플레이오프 2~5위로 두 팀이 오르내렸다. 10팀으로 치르던 시즌은 그 규칙으로 끝난다.)
- 상·하위 리그 팀이 맞붙는 승강전은 없다. 3전 2선승도 없다.
- 내 구단이 플레이오프에 나가면 최대 3경기(준결승 2경기 + 결승)를 치른다.

#### 구장 등급

✅ 축구에는 신청 단계가 없다. 대신 잉글랜드의 구장 등급 심사처럼 **경기장 레벨**이 기준에 닿아야 승격할 수 있다.

| 현재 리그 → 목표 리그 | 필요한 경기장 (💡) |
|---|---|
| 6부 → 5부 | Lv2 (간이 관중석) |
| 5부 → 4부 | Lv3 |
| 4부 → 3부 | Lv4 |
| 3부 → 2부 | Lv5 |
| 2부 → 1부 | Lv6 |

- 시즌이 끝날 때 기준에 못 미치면 자동 승격과 플레이오프 자격이 다음 순위 팀으로 넘어간다.
- 인지도는 관중·스폰서·영입에만 쓰인다. 승격 조건이 아니다.
- AI 팀은 기준을 채운 것으로 본다.

### 승격하면

- 💡 큰 인지도 보너스와 "승격 지원금"을 받는다.
- 승강 플레이오프 경기도 1시간마다 한 경기씩 진행한다.

### 강등

✅ 야구는 10위가 자동 강등되고 9위는 승강 플레이오프에서 지면 강등된다. 축구는 맨 아래 세 팀(18~20위)이 자동 강등된다.

- 6부 시민 아마추어는 최하위 리그라 강등이 없다.
- ✅ 강등되면 다른 구단의 **영입 오퍼가 몰려온다**. 실제 야구처럼 주축 선수를 뺏길 수 있다. 판 돈은 구단 자금에 들어온다 → [선수 영입](05-player-recruitment.md#이적-오퍼)
- 💡 강등되면 인지도가 크게 떨어지고, 스폰서 수입이 줄어든다.

## 시즌 흐름

```
정규시즌 36라운드 ─▶ 시상식 ─▶ 플레이오프 ─▶ 오프시즌 (친선 5경기 + 이적 시장) ─▶ 다음 시즌
  └ 야구·농구: 1~24라운드 트레이드 가능, 25라운드부터 마감
  └ 축구: 1~3라운드(여름 이적 기간의 끝), 17~20라운드(겨울 이적 기간)에만 이적 가능
```

### 오프시즌

✅ 시즌이 끝나면 **친선 경기 약 5경기**를 치른다. 이 기간이 **이적 시장**이다.

1. **오프시즌 시작**
   - 나이 +1, 은퇴 발표
   - 연봉 인상 → [선수 영입](05-player-recruitment.md#계약과-연봉)
   - 계약 만료 선수 목록 표시, 재계약 협상 시작
   - FA 시장 열림, 이적 오퍼 시작 (강등 팀에 집중)
2. **친선 경기 1~5** (평소처럼 1시간마다, 최대 3경기 쌓임) → [경기](02-match.md#친선-경기)
   - ✅ 친선 경기가 끝날 때마다 이적 오퍼, FA 협상 결과, 재계약 답변이 들어온다
3. 친선 3경기 뒤: 야구는 **신인 드래프트** (3부 이상), 축구는 **유소년 승급** (모든 리그. 축구에는 드래프트가 없다)
4. **오프시즌 끝** (친선 5경기 후)
   - 재계약하지 않은 계약 만료 선수는 떠난다 (FA 시장으로)
   - 새 시즌 일정 생성, 이적 시장 닫힘

💡 오프시즌 길이: 친선 5경기 = 최소 5시간. 이적 시장을 천천히 둘러볼 시간이 된다.

## 상대 팀

✅ 상대 팀과 리그는 KBO를 기준으로 만든다.

✅ 상대 팀은 모두 **가상 구단**이다. 리그 운영 방식(10팀, 일정, 순위, 규칙)은 KBO를 따른다.

✅ 1부 프로 리그 10팀은 실제 KBO 구단의 연고지와 애칭을 **우리말로 옮긴 이름**을 쓴다. 야구팬이 보면 바로 알아보고 웃을 수 있는 이름이 목표다.

| 연고지 | 가상 구단 | 모티브 |
|---|---|---|
| 광주 | **광주 호랑이** | 타이거즈 |
| 대구 | **대구 사자** | 라이온즈 |
| 부산 | **부산 거인** | 자이언츠 |
| 대전 | **대전 독수리** | 이글스 |
| 서울 잠실 | **잠실 곰** | 베어스 |
| 서울 잠실 | **서울 쌍둥이** | 트윈스 |
| 서울 고척 | **고척 영웅** | 히어로즈 |
| 인천 | **인천 상륙단** | 랜더스 |
| 수원 | **수원 마법사** | 위즈 |
| 창원 | **창원 공룡** | 다이노스 |

- 게임 시작 시 1부에 있는 팀들이다. 시즌이 지나면 강등될 수도 있다.

### 지키는 선

애칭을 우리말로 옮기는 것 말고는 실제 구단과 겹치지 않게 한다. 구단명과 엠블럼은 등록 상표이고, 실제 선수 이름은 퍼블리시티권 문제가 있기 때문이다.

| 쓰지 않는 것 | 대신 |
|---|---|
| 영문 애칭 그대로 (타이거즈, 라이온즈 등) | 우리말로 옮긴 애칭 |
| 모기업·스폰서 이름 (실제 기업명 전부) | 연고지 이름만 |
| 실제 엠블럼, 유니폼 색 조합 | 직접 디자인한 엠블럼과 색 |
| 실제 선수·감독 이름 | 자동 생성 이름. 💡 KBO 현역·주요 은퇴 선수 이름은 생성기에서 걸러낸다 |

- README와 앱 정보 화면에 "KBO 및 각 구단과 무관한 비공식 팬 프로젝트" 면책 문구를 넣는다.
- 💡 설정에서 모든 팀 이름을 바꿀 수 있게 한다 (Football Manager처럼). 문제가 생기면 기본 이름만 바꾸면 된다.

### 하위 리그 팀

💡 하위 리그 AI 팀은 지역 시민 구단, 대학, 실업팀 느낌의 이름을 자동으로 만든다 (예: "청주 시민 야구단", "한빛대학교", "동해 철강 야구부"). 실제 학교·기업 이름은 쓰지 않는다.

💡 AI 팀도 시즌마다 선수가 성장하고 바뀌며, 승격·강등된다. 리그 구성이 해마다 조금씩 달라진다.

## 컵대회 (선수 모드)

리그와 별개로 모든 구단(야구 60개, 축구 120개, 농구 60개)이 나오는 단판 승부 대회가 시즌마다 열린다. 야구는 1부에서 가장 강한 네 팀이 1라운드를 쉬어 32팀이 되고, 그 뒤로 32강·16강·8강·준결승·결승을 치른다. 축구는 여덟 팀이 쉬어 64팀이 되고 64강부터 치른다 (리그 3·8·13·18·23·29·35라운드 뒤). 매 라운드 다시 추첨하고 아랫 리그 구단이 홈에서 치른다. 야구는 리그 4·10·16·22·28·33라운드를 마친 뒤 한 라운드씩 열리며, 농구는 야구와 같은 일정이다. 반드시 승부가 난다 (야구: 연장 끝까지, 축구: 연장과 승부차기, 농구: 연장). 리그 순위와 시즌 기록에는 들어가지 않는다. 보상은 [야구 선수 모드](09-baseball-player-mode.md), [축구 선수 모드](08-player-mode.md), [농구 선수 모드](11-basketball.md)에 있다.
