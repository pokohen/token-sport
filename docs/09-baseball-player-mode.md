# 9. 야구 선수 모드

구단을 운영하는 대신 **야구 선수 한 명**이 되어 커리어를 보내는 모드다. 타자 또는 투수를 골라 키운다.

[축구 선수 모드](08-player-mode.md)와 틀이 같다. 훈련 포인트, 계약, 이적, 은퇴는 이 문서가 기준이다. 여기 없는 내용(6부 리그와 승강, 일정, 야구 규칙과 경기 엔진, 능력과 잠재력, 나이 곡선, 세계 시뮬레이션)은 1~6번 문서를 그대로 따른다.

## 한 줄 소개

✅ 내가 야구 선수가 된다. 타자 또는 투수.

💡 16세에 6부 시민 구단에 입단해, 코딩하며 쓴 토큰으로 훈련하고, 더 높은 리그의 구단으로 옮겨 가며 1부 프로 리그의 스타가 되는 것이 목표다.

| | 구단 모드 | 선수 모드 |
|---|---|---|
| 내가 되는 것 | 구단주 겸 단장 | 선수 한 명 |
| 토큰 | 구단 자금 | 훈련 포인트 |
| 키우는 것 | 구단 | 내 선수 (능력치, 감독 신뢰, 명성) |
| 올라가는 길 | 구단이 승격한다 | 구단이 승격하거나, 내가 윗 리그 구단으로 옮긴다 |
| 실패 | 파산 | 없음 (방출돼도 다른 구단을 찾는다) |
| 끝 | 없음 | 은퇴 |

## 핵심 루프

```
코딩한다 (토큰 사용)
   ↓
훈련 포인트가 쌓인다
   ↓
훈련한다: 훈련을 골라 능력을 올린다 (경기 사이에 다섯 번)
   ↓
1시간마다 경기에 나선다
   ↓
경기 평점이 나온다
   ↓
평점이 쌓이면 감독 신뢰와 명성이 오른다
   ↓
연봉이 오르고, 더 큰 구단에서 제안이 온다
```

## 시작

💡 선수를 만들 때 정하는 것:

| 항목 | 내용 |
|---|---|
| 이름 | 직접 입력 |
| 유형과 포지션 | **타자**: 포수, 1루수, 2루수, 3루수, 유격수, 좌익수, 중견수, 우익수, 지명타자 / **투수**: 선발, 불펜. 커리어 중에는 바꿀 수 없다 |
| 타석과 투구 | 우타·좌타, 우투·좌투 |
| 출신 | 도시를 고른다 (선수 소개에만 쓴다) |
| 시작 포인트 | 5개를 내 포지션의 능력치에 나눠 넣는다 (하나에 2개까지) |

💡 정해져 있는 것:

- **나이 16세**로 시작한다.
- 6부 시민 아마추어 리그의 중위권 구단에 입단한다. 같은 포지션에서 가장 약한 선수의 자리를 넘겨받는다.
- **타고난 재능**: 선수마다 다르다. 만들 때 난수로 정해진다.
  - **타고난 능력**: 15~30 사이. 시작 포인트는 이 위에 더해진다.
  - **잠재력(성장 한계)**: 68~95 사이. 숫자는 숨겨져 있고, 입단할 때 스카우트 평가(소식)와 홈 탭의 선수 카드에 **재능 등급**으로만 나온다: 천재(90 이상) · 특급 유망주(84 이상) · 유망주(77 이상) · 평범(71 이상) · 노력파(그 아래).
- **시작 포인트 5개**: 만들 때 내 포지션의 능력치에 직접 나눠 넣는다. 포인트 하나에 그 능력치가 +3 오르고, 능력치 하나에는 2개까지 넣는다 (비중이 큰 능력치 하나에 몰아넣으면 포지션마다 시작 능력이 크게 벌어져서 막았다. 가장 좋게 넣으면 능력 +3.5 ~ +5.4). 넣지 않은 포인트는 사라진다.
- 세계는 구단 모드와 똑같이 만든다. 6개 리그 60개 구단이 모두 CPU 구단이다.

마무리 투수는 고를 수 없다. 세이브 상황에만 나와서 나오지 않는 경기가 너무 많다.

## 토큰 → 훈련 포인트

✅ 토큰 수를 가중치 없이 그대로 쓴다.

```
훈련 포인트 = 총 토큰 = input + output + cache_write + cache_read
```

- 선수를 만든 뒤에 쓴 토큰만 센다. 시작할 때 100,000 포인트를 갖고 있다.
- 훈련 포인트는 훈련에만 쓴다. 연봉은 따로 쌓인다.

### 훈련

✅ 훈련 탭에서 훈련을 고른다. **어떤 훈련이든 능력(CA)이 같은 양만큼 오른다.** 포지션에서 덜 중요한 능력치일수록 한 번에 많이 오른다 (능력치 증가 = 리그별 훈련 효과 ÷ 그 능력치의 비중). 타자와 투수의 훈련이 다르다.

**리그에 따라 훈련 효과와 비용이 달라진다.** 윗 리그일수록 훈련 한 번에 더 많이 오르고 더 비싸다. 시설과 코치가 좋아지는 만큼이다.

| 리그 | 6부 | 5부 | 4부 | 3부 | 2부 | 1부 |
|---|---|---|---|---|---|---|
| 훈련 한 번에 오르는 능력 | 0.025 | 0.03 | 0.035 | 0.04 | 0.045 | 0.05 |
| 한 시즌 내내 다 하면 (220번쯤) | +5.5 | +6.6 | +7.7 | +8.8 | +9.9 | +11 |
| 비용 배수 | 0.5배 | 0.7배 | 1.0배 | 1.3배 | 1.6배 | 2.0배 |

훈련 한 번은 작다. 한 시즌 동안 꾸준히 해야 눈에 띈다. 능력치 값에 따른 비용(아래)은 따로 곱해지고, 능력은 화면에 소수 한 자리까지 나온다.

**성장 속도의 아래와 위.** 숫자는 두 경우를 재서 맞췄다.

| | 한 시즌에 오르는 능력 | 여덟 시즌 뒤 |
|---|---|---|
| **경기만 뛴다** (훈련을 한 번도 안 한다) | +3~4 | 능력 50~58, 3~4부 |
| **훈련을 하나도 빼먹지 않는다** (포인트가 넘친다) | +9~14 | 5시즌에 능력 75~81, 5~7시즌에 1부 |

실제 선수는 그 사이에 있다. 윗 리그로 갈수록 능력치가 높아 훈련 비용이 가파르게 비싸지므로(능력치 70이면 한 번에 400만 포인트 × 리그 배수), 포인트가 모자라면 훈련을 다 하지 못하고 아래 기준 쪽으로 내려간다. 다시 재려면 `TB_PROBE=pace swift test --filter CareerOfferProbe` (16분). 마지막으로 잰 것은 1.2.0 (평점이 오른 1.1.0 뒤에도 거의 그대로였다).

예전에는 훈련 한 번에 능력이 0.25씩 올라서, 훈련을 다 하면 한 시즌에 20~50이 오르고 세 시즌 만에 1부에 닿았다. 그래서 훈련 효과를 줄이고 리그에 따라 달라지게 했다 (6부 0.025 → 1부 0.05).


| 타자 훈련 | 오르는 능력치 | | 투수 훈련 | 오르는 능력치 |
|---|---|---|---|---|
| 티 배팅 | 컨택 | | 불펜 피칭 | 구위 |
| 웨이트 트레이닝 | 파워 | | 제구 훈련 | 제구 |
| 선구안 훈련 | 선구안 | | 변화구 연마 | 변화구 |
| 주루 훈련 | 주력 | | 러닝 | 체력 |
| 펑고 | 수비 | | | |
| 롱토스 | 어깨 | | | |

포지션별 능력 비중 (괄호 안은 훈련 한 번에 그 능력치가 오르는 양, 6부~1부):

| 포지션 | 비중 |
|---|---|
| 야수 (포수·지명타자 제외) | 컨택 28% (+0.09~0.18) · 파워 22% (+0.11~0.23) · 수비 17% (+0.15~0.29) · 선구안 15% (+0.17~0.33) · 주력 10% (+0.25~0.50) · 어깨 8% (+0.31~0.62) |
| 포수 | 컨택 24% (+0.10~0.21) · 수비 24% (+0.10~0.21) · 파워 18% (+0.14~0.28) · 어깨 16% (+0.16~0.31) · 선구안 13% (+0.19~0.38) · 주력 5% (+0.50~1.00) |
| 지명타자 | 컨택 36% (+0.07~0.14) · 파워 34% (+0.07~0.15) · 선구안 22% (+0.11~0.23) · 주력 8% (+0.31~0.62) |
| 선발 투수 | 구위 32% (+0.08~0.16) · 제구 28% (+0.09~0.18) · 변화구 22% (+0.11~0.23) · 체력 18% (+0.14~0.28) |
| 불펜 투수 | 구위 40% (+0.06~0.12) · 제구 28% (+0.09~0.18) · 변화구 27% (+0.09~0.19) · 체력 5% (+0.50~1.00) |

- 처음에는 한 번에 능력치 +1이었다. 그러면 능력치가 4개인 투수·지명타자가 6개인 야수보다 1.5배 빨리 컸다. 전문가 검토 뒤에 지금 방식으로 바꿨다 → [야구 검토](review/baseball.md).
- 능력은 어느 훈련으로나 똑같이 오르므로, **무엇을 올릴지는 경기에서 무엇을 하고 싶은지로 고른다.** 파워는 홈런을, 컨택은 타율을, 선구안은 볼넷을, 구위는 삼진을, 제구는 볼넷과 장타 억제를, 체력은 던질 수 있는 공 수를 늘린다.
- **비용**은 그 능력치의 지금 값으로 정해지고, **훈련할 때마다 조금씩 오른다.** 계단식으로 뛰지 않는다.

| 능력치의 지금 값 | 훈련 한 번에 드는 포인트 (💡) |
|---|---|
| 25 | 25만 |
| 40 | 62만 |
| 50 | 116만 |
| 60 | 215만 |
| 70 | 397만 |
| 80 | 736만 |
| 90 | 1,361만 |

- 설정의 **가격 난이도 슬라이더(10%~200%)** 가 이 비용에도 적용된다.

💡 토큰을 많이 쓴 날 하루 만에 다 크지 않도록 두는 제한:

1. **훈련 횟수**: 경기와 경기 사이에 **다섯 번**까지만 훈련한다. 쓰지 못한 포인트는 그대로 남는다. 선발 투수는 **등판하지 않는 날에 한 번 더** 한다.
   - **추가 훈련** (설정 탭에서 켠다, 기본은 꺼짐): 정해진 횟수를 넘겨서도 훈련할 수 있다. 한 번마다 비용이 1.5배씩 더 든다 (1.5배, 2.25배, 3.4배…). 한계 돌파 훈련도 같이 비싸진다. 다음 경기를 치르면 처음 값으로 돌아간다.
   - **크리티컬**: 훈련마다 1% 확률로 세 배 오른다 (포인트는 그대로, 한계와 99는 넘지 못한다).
2. **잠재력**: 능력은 잠재력을 넘지 못한다. 남은 여유가 10 이하면 비용이 2배다.
3. **리그 한도는 없다**: 예전에는 지금 리그 수준 +5까지만 올랐지만 없앴다. 어느 리그에서든 타고난 한계(잠재력)까지 훈련할 수 있다.
4. **나이**: 31세부터는 훈련으로 올릴 수 없다. 31~33세에는 주력·수비·구위·체력이 조금씩 내려가고 (선구안과 제구는 조금 는다), 34세부터는 시즌마다 모든 능력치가 떨어진다.

- 포인트를 쓰지 않아도 경기를 뛰면 조금씩은 큰다. 구단 모드의 성장 공식이 내 선수에게도 적용되지만, **15%만** 반영한다 (한 시즌에 능력 +3~4). 나머지는 훈련으로 올린다. 얼마나 컸는지는 경기 결과에 "이번 경기 성장: 능력 +0.10"처럼 적힌다.

💡 **한계 돌파 훈련**: 3,000만 포인트로 잠재력을 +1 넓힌다 (훈련 횟수를 한 번 쓴다, 최대 99). 잠재력에 닿은 뒤에도 토큰을 쓸 곳이 남는다.

**성장 속도** (경기마다 300만 토큰을 쓰고, 윗 리그 제안을 모두 받아들이는 자동 진행으로 잰 값): 첫 시즌에 능력 20대 초반 → 40대 후반, 18~20세에 1부에 닿고, 그 뒤로는 시즌에 +1~2씩 오른다. 포지션에 따른 차이는 거의 없다. 토큰을 덜 쓰거나 제안을 가려 받으면 더 느리다.

## 경기

✅ 경기 기회(1시간에 하나, 최대 3개), 직접 눌러 시작, 약 15분의 실시간 중계와 배속은 구단 모드와 같다. 경기 기회가 없을 때 훈련 포인트로 사서 바로 치를 수도 있다 → [경기](02-match.md#토큰으로-바로-경기). 내 구단의 경기가 통째로 중계된다.

- 스코어보드 아래에 **내 선수 줄**이 생긴다: 지금까지의 평점과 기록.
- 내 선수가 나온 장면은 문자 중계에서 강조된다.
- 포메이션에 해당하는 라인업, 타순, 투수 운용은 감독(CPU)이 정한다. 경기 중에는 개입하지 않는다.

### 출전

타자와 투수는 하는 일이 달라서 출전 규칙도 다르다.

| 유형 | 출전 (💡) | 감독 신뢰가 하는 일 |
|---|---|---|
| **타자** | 매 경기 선발로 나온다 | 신뢰가 높으면 타순이 앞으로 당겨진다 |
| **선발 투수** | 쉬는 날을 채우면 반드시 선발로 나온다. 시민 리그는 3경기에 한 번, 3부부터는 5경기에 한 번 | 신뢰가 높으면 더 오래 맡긴다 (교체 투구 수 70~110구, 교체 실점 4~6점) |
| **불펜 투수** | 선발이 내려가면 가장 먼저 올라온다. 자주 나오지만 짧게 던진다 (28구에서 바뀐다). 직전 경기에 25구 넘게 던졌거나 이틀 연속 나왔으면 그날은 맨 뒤로 밀린다 | — |

✅ **선발 투수가 나오지 않는 날**에는 팀 경기를 그대로 지켜보고, 대신 훈련을 한 번 더 한다. 선수를 만들 때 미리 알려 준다.

- "내 선발 투수는 쉬는 날 없이 매 경기 나온다"는 안도 있었다. 전문가 검토에서 다승·탈삼진 기록이 다른 투수와 비교가 되지 않게 된다는 의견이어서 택하지 않았다.

💡 경기가 끝나면 1.0~10.0의 평점이 나온다. 타자는 6.1, 선발 투수는 6.2, 불펜 투수는 6.0에서 시작해 한 일을 더하고 뺀다. 팀이 이기면 +0.2, 지면 −0.2.

|---|---|---|---|---|---|---|---|
| 단타 | +0.55 | | 아웃 하나 | +0.12 | | 아웃 하나 | +0.25 |
| 2루타 | +0.8 | | 자책점 | −0.45 | | 자책점 | −0.9 |
| 3루타 | +1.0 | | 비자책 실점 | −0.2 | | 비자책 실점 | −0.3 |
| 홈런 | +1.4 | | 탈삼진 | +0.08 | | 탈삼진 | +0.1 |

## 내 선수가 쌓는 것

| 값 | 뜻 | 어디에 쓰이나 |
|---|---|---|
| **능력치·능력(CA)** | 실력 | 경기, 이적 제안 |
| **감독 신뢰** (0~100) | 지금 구단 감독의 평가 | 타순, 선발 투수를 맡기는 길이, 재계약 |
| **명성** (0~100) | 리그에 이름이 알려진 정도 | 이적 제안이 오는 빈도, 연봉 협상 |
| **통산 기록** | 경기, 타격·투구 기록, 평균 평점, 수상, 거쳐 간 구단 | 커리어 화면, 은퇴 뒤 명예의 전당 |
| **통산 수입** | 받은 연봉의 합 | 점수처럼 보여 준다 |

- **감독 신뢰**: 40에서 시작한다. 평점 7.0 이상이면 오르고 6.0 아래면 내린다 (한 경기에 최대 ±6, 친선 경기는 절반). 훈련할 때마다 +0.1. 구단을 옮기면 40에서 다시 시작한다.
- **명성**: 평점 6.5를 넘긴 경기마다 오른다. 리그마다 한도가 있다 (6부 20 → 1부 100). 선발 투수는 나오는 경기가 적어 한 경기가 세 배로 반영된다. 시즌이 바뀔 때 10% 줄어든다.
- **시즌 목표**: 시즌이 시작될 때 감독이 하나 준다 (타자: 안타 20~36개, 선발: 시민 리그 3승·3부부터 2승, 불펜: 18경기 등판). 선발은 5이닝을 던져야 승리 투수가 되므로 승수 목표가 낮다. 채우면 감독 신뢰 +10과 명성 +3, 채우지 못하면 감독 신뢰 −5.
- **컵대회**: 60개 구단이 모두 나오는 단판 승부. 1부의 강한 네 팀이 1라운드를 쉬고(60 → 32), 매 라운드 다시 추첨하며 아랫 리그 구단이 홈이다. 리그 4·10·16·22·28·33라운드 뒤에 한 라운드씩 열린다. 이기면 명성 +1, 윗 리그를 잡으면 리그 차이마다 +2, 우승은 명성 +12와 감독 신뢰 +5. 순위와 시즌 기록에는 들어가지 않는다.
- **컨디션**: 경기마다 최상(+6%) / 좋음(+3%) / 보통 / 나쁨(−3%) / 최악(−6%) 중 하나가 정해져 그 경기의 능력치에 곱해진다 (비율 10·25·40·20·5%).
- **기세**: 평점 7.0 이상이 세 경기 이어지면 능력치 +2%와 명성 1.25배, 5.5 이하가 세 경기 이어지면 −2%. 연속 안타(투수는 연속 무자책) 경기 수와 개인 최고도 센다.
- **라이벌**: 같은 리그 다른 구단의 같은 역할 선수 중 나보다 능력이 2쯤 높은 또래. 그 구단과의 경기에서 둘 다 뛰면 평점으로 맞대결 승패를 가리고, 이기면 명성 +1. 리그가 달라지거나 새 시즌에 내가 5 넘게 앞서면 바뀐다.
- **실전 경험**: 토큰으로 사서 치른 경기에서는 능력이 `0.05 + (평점 − 6) × 0.08` (0.05~0.3) 오른다. 한계는 넘지 못한다.
- **명성 활동**: 커리어 탭에서 훈련 포인트를 들여 명성을 올린다. 팬 사인회 (150만 P, +1.0), 지역 방송 인터뷰 (400만 P, +2.5), 유소년 교실 봉사 (800만 P, +4.0, 감독 신뢰 +1). 경기 사이에 한 번이고, 리그의 한도에 가까울수록 덜 오른다 (`명성 × (한도 − 지금) / 한도`).
- **이름 바꾸기**: 설정 탭에서 선수 이름을 바꿀 수 있다 (12자까지).
- **수상**: 리그 MVP, 타격왕, 홈런왕, 다승왕, 평균자책점 1위, 탈삼진왕을 받으면 명성 +8. MVP는 구단 모드와 같이 잠재력이 +3~8 오른다.

## 구단과의 관계

💡 내 소속 구단도 CPU 구단이다. 시설, 영입, 방출, 승격을 모두 구단이 알아서 한다.

- 구단 자금, 파산, 승격 신청, 이적 시장 화면은 없다. 대신 **나에게 오는 제안**만 본다.
- CPU 팀 맞춰주기는 끈다 (기준이 될 "내 구단"이 없다).
- 구단은 내 선수를 마음대로 내보내거나 은퇴시키지 않는다.

### 계약과 연봉

- 처음 계약은 2시즌. 연봉은 능력으로 정해진다 (구단 모드의 선수 연봉 공식 그대로).
- 정규시즌 경기마다 연봉의 36분의 1이 **통산 수입**에 쌓인다. 시즌이 끝나면 연봉이 오른다.
- 계약이 끝나면 구단이 **재계약 제안**을 한다. 감독 신뢰가 30 아래면 제안하지 않는다.

### 이적

✅ 이적 기간은 구단 모드와 같다: 오프시즌(친선 5경기)과 정규시즌 24라운드까지.

- 이적 기간에는 경기가 끝날 때, **관심도가 문턱을 넘은 스카우트의 구단**이 제안한다 → [스카우트](#스카우트).
- **제안 내용**: 구단, 리그, 연봉, 계약 기간, 예상 입지(주전 / 주전 경쟁 / 유망주).
- **내 선택**: 수락 / 거절 / 연봉 올려 달라고 하기 (제안마다 한 번, 실패하면 이적 제안은 사라진다). 다음 경기가 끝날 때까지 답하지 않으면 사라진다.
- 구단을 옮기면 열 경기 동안은 새 제안이 오지 않는다.
- **이적 요청**: 이적 기간마다 한 번. 지켜보던 구단들의 관심도가 10 오르고, 제안의 문턱이 70에서 50으로 낮아지고, 새 스카우트가 더 잘 온다. 대신 감독 신뢰가 10 떨어진다.

### 스카우트

✅ 이적 제안은 아무 구단에서나 갑자기 오지 않는다. **나를 지켜보던 구단**에서, 관심이 충분히 쌓였을 때 온다. 커리어 탭의 "스카우트" 카드에서 본다.

**누가 지켜보는가** (한 번에 세 구단까지)

| 구단 | 조건 |
|---|---|
| 윗 리그의 구단 (**두 리그 위까지**) | 가면 주전이나 주전 경쟁일 때. 바로 위 리그는 유망주로도 본다: 23세 이하이고, 명성이 지금 리그 한도의 80% 이상이고, 능력이 그 리그 최저 수준 −8 이상일 때 |
| 같은 리그의 구단 | 지금 구단에서 주전이 아닌데 그 구단에 가면 주전이나 주전 경쟁일 때만. 이미 주전인 선수는 같은 리그 구단이 지켜보지 않는다 (계약이 끝난 선수는 주전이어도 지켜본다) |

- 한 번에 뛰어오를 수 있는 것은 두 리그까지다. 6부 선수를 3부 이상의 구단이 지켜보지 않고, 1부 선수는 1부 구단만 본다. 두 리그를 뛰어오르려면 그 구단에서 곧바로 주전을 다툴 실력이어야 한다 (유망주로는 못 간다).
- 내가 뛴 경기가 끝날 때마다 새 스카우트가 올 수 있다: 기본 12%에 명성 ÷ 250을 더한다 (명성 50이면 32%). 평점 7.0 이상이면 +12%p, 이적을 요청했으면 +30%p, 계약이 끝났으면 +40%p.
- 처음 관심도는 20~35에 명성 ÷ 4를 더한 값이다. 가면 주전인 구단은 8이 더 높다.
- 세 자리가 다 찼을 때는 **가면 주전인 구단**만 새로 올 수 있고, 그때는 관심도가 가장 낮은 "주전이 아닌 자리로 보는" 구단이 밀려난다. 오르지도 식지도 않는 구단이 자리를 차지하고 있지 않게 하는 규칙이다.

**관심도** (0~100)

```
경기마다 변화 = (평점 − 기준) × 8 × 희소성 + 입지 + 명성 ÷ 100
```

- **기준**: 야구 6.2, 축구·농구 6.0 (명성의 기준보다 0.3 낮다). 평점 7.0이면 야구 +6.4, 축구 +8이다.
- **희소성**: 선발 투수는 나오는 경기가 적어서 3배 (명성과 같다).
- **입지**: 그 구단에 가면 주전이면 경기마다 +3.5, 주전 경쟁이면 +1.2. 벤치에 묶여 평점이 6점 근처인 선수도, 주전으로 써 줄 구단의 관심은 꾸준히 쌓인다.
- 친선 경기는 절반만 움직인다. 내가 나오지 않은 경기는 바뀌지 않는다.
- 관심도가 0이 되면 그 구단은 떠난다. 더는 데려갈 수 없게 된 구단(리그가 달라졌다, 내가 주전이 됐다, 그 구단에 더 좋은 선수가 들어왔다)도 떠난다. 떠날 때는 경기 결과에 한 줄이 나온다.
- 새 시즌에는 관심도의 85%가 남는다.

**스카우트가 직접 오는 경기**

경기가 끝날 때 30%의 확률로, 지켜보던 구단 가운데 하나가 **다음 경기를 직접 보러 온다.** 홈 탭과 스카우트 카드에 미리 나온다. 그 경기에서는 그 구단의 관심도가 **두 배**로 움직인다. 잘하면 크게 오르고 못하면 크게 내린다. 출전하지 못하면 헛걸음이다.

**제안**

- 관심도가 **70**을 넘은 구단이 이적 기간에 제안한다. 이적 기간이 아니면 열릴 때까지 기다린다.
- 관심도가 70을 넘긴 만큼 연봉을 더 부른다 (관심도 90이면 10% 더).
- 문턱은 이적을 요청했으면 **50**, 계약이 끝났으면 **35**로 낮아진다.
- 제안을 **거절하거나, 답하지 않거나, 연봉 협상이 깨지면 그 구단은 떠난다.** 다시 눈에 띄면 처음부터 지켜보기 시작한다.
- 구단을 옮기면 지켜보던 구단이 모두 떠나고, 새 구단에서 처음부터 다시 쌓는다.

시뮬레이션 (자동 진행으로 세 시즌. 유격수, 선발 투수, 축구 공격수, 농구 스몰 포워드 둘(토큰 많이 · 적게)을 시드 두 개씩, 모두 열 번):

| | 스카우트를 넣기 전 | 넣은 뒤 |
|---|---|---|
| 세 시즌 동안 받은 제안 | 4~13건 | 4~17건 |
| 구단을 옮긴 횟수 | 3~5번 | 4~6번 |
| 세 시즌 뒤의 리그 | | 열 번 중 다섯 번은 같고, 두 번은 한 리그 높고, 세 번은 낮았다 (한 리그 낮은 것 둘, 두 리그 낮은 것 하나) |

시드가 둘뿐이라 편차가 크다. "예전보다 크게 느려지지는 않았다" 정도로만 읽는다. 처음 넣었을 때는 열 번 중 다섯 번이 더 낮은 리그에서 끝나서, 관심이 쌓이는 속도를 올리고 자리가 막히지 않게 밀어내는 규칙을 넣었다. 다시 재려면 `TB_PROBE=1 swift test --filter CareerOfferProbe`.

💡 **무소속**: 오프시즌이 끝날 때까지 계약이 없으면 무소속이 된다. 지금 능력에 맞는 리그의 구단 두세 곳이 입단을 제안하고, 하나를 골라야 경기에 나설 수 있다. 한 단계 아래 리그로 내려갈 수도 있다.

### 은퇴

- 한 시즌을 끝까지 치른 뒤부터 오프시즌에 스스로 은퇴할 수 있다 (나이 제한 없음). 38세(골키퍼 41세)가 되는 오프시즌에는 저절로 은퇴한다.
- 은퇴하면 **커리어 기록**이 나온다: 거쳐 간 구단, 통산 기록, 평균 평점, 수상, 최고 능력, 통산 수입.
- 기록은 **명예의 전당**에 칭호와 함께 남고 (동네 스타 / 프로 선수 / 1부 스타, 수상 경력이 있으면 시민 리그의 영웅 / 프로 스타 / 전설), 같은 세계에서 새 선수를 만들어 다시 시작한다. 훈련 포인트는 처음부터 다시 쌓는다.

## 화면

| 탭 | 내용 |
|---|---|
| 홈 | 내 선수 카드(능력, 감독 신뢰, 명성, 지난 경기), 훈련 포인트, 시즌 목표, 다음 경기, 소식 |
| 경기 | 구단 모드와 같다. 투수 운용 방침 대신 내 선수 줄 |
| 리그 | 구단 모드와 같다 (승격 신청은 없다) |
| 훈련 | 훈련 고르기, 남은 훈련 횟수, 한계 돌파 훈련 |
| 커리어 | 들어온 제안, 계약, 이번 시즌과 통산 기록, 시즌별 기록, 팀 동료 |
| 설정 | 구단 모드와 같다. 모드 전환이 여기에 있다 |

상단바에는 구단 자금 대신 훈련 포인트가 나온다 (예: `3.2M P`).

## 저장과 모드 전환

- 저장 파일은 `save-baseball-player.json`으로 따로 둔다. 야구 구단, 축구 구단, 야구 선수를 각각 갖고 있을 수 있다.
- 지금 하고 있는 것을 적어 두는 `save.sport`에 `baseball-player` 값을 더했다. 예전 값은 그대로 읽힌다.
- 설정의 "종목" 카드가 **"모드"** 카드가 되었다. 처음 시작하는 화면에서도 셋 중에 고른다.
- ✅ 한 번에 하나만 한다. 쉬는 구단·선수는 그동안 쓴 토큰을 받지 않고 경기 기회도 쌓이지 않는다.

## 소속 구단의 승격

내 구단도 다른 CPU 구단과 똑같이 승격하고 강등된다 → [리그](03-league.md#야구-와일드카드와-승강-플레이오프). 구단이 와일드카드나 승강 플레이오프에 나가면 그 경기에도 내 선수가 출전한다. 승격하면 연봉이 10% 오른다.

## 아직 없는 것

- 특성 얻기 (찬스에 강함 등을 커리어 중에 얻기)
- 대타·대수비 같은 경기 중 교체 (지금 엔진에는 야수 교체가 없다)
- 마무리 투수, 투타 겸업
- 연봉을 쓰는 곳 (개인 트레이너, 장비)
- 부상, 국가대표
- 은퇴 뒤 구단주가 되어 구단 모드로 넘어가기
