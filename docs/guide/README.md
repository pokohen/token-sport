# 플레이 가이드

어떻게 시작하고, 화면에서 무엇을 누르고, 어떻게 키워 가는지 적는다.
규칙의 근거와 수치는 [기획 문서](../README.md)에 있다.

## 선수 키우기

| | 가이드 | 한 줄 |
|---|---|---|
| ⚾ | [야구 개인 성장](baseball-player.md) | 타자는 매 경기 선발, 투수는 등판 간격대로. 타자와 투수의 훈련이 다르다 |
| ⚽ | [축구 개인 성장](football-player.md) | 실력으로 주전을 따낸다. 선발이 아니면 후반에 교체로 들어가고, 경기 전에 플레이 스타일을 고른다 |
| 🏀 | [농구 선수 모드](../11-basketball.md) | 다섯 포지션. 선발을 따내고, 벤치에서 시작하면 감독 신뢰에 따라 8~24분을 뛴다. 경기 전에 플레이 스타일을 고른다 |

처음 화면에서 셋 중 하나를 고른다. 셋 다 만들 수 있고 설정 탭에서 오간다.

**어느 쪽부터 할까**: 매 경기 내 선수를 보고 싶으면 야구 타자가 가장 단순하다. 경쟁해서 자리를 따내는 맛은 축구와 농구 선수 쪽이다. 농구는 한 경기에 내 선수가 나오는 장면이 가장 많다.

## 설치, 업데이트, 초기화

터미널에서 실행한다. 저장소를 직접 받을 필요는 없다. 배포 파일이 올라와 있으면 그것을 내려받으므로 Xcode도 필요 없다 (없으면 이 맥에서 직접 만들고, 그때는 Xcode 16 이상이 필요하다). 저장소를 직접 받아 개발하는 경우의 명령(`Scripts/update.sh`)은 [README](../../README.md#설치)에 있다.

| 하려는 것 | 명령 | 선수 저장 파일 |
|---|---|---|
| 처음 설치 | `curl -fsSL https://raw.githubusercontent.com/pokohen/token-sport/main/Scripts/install.sh \| bash` | 없음 (처음 화면부터) |
| **업데이트** | 같은 명령을 다시 실행한다 | **그대로**. 앱만 새 버전으로 바뀐다 |
| **초기화** | 앱의 설정 탭 → 초기화 (명령이 아니다) | 지금 모드만, 또는 전부 처음부터. 예전 것은 백업으로 남는다 |

- **새 버전 알림과 업데이트**: 앱이 켤 때와 여섯 시간마다 새 버전이 있는지 확인한다. 있으면 알림이 한 번 오고, 팝오버 위쪽에 "새 버전이 나왔습니다" 줄이, 설정 탭에 "업데이트" 카드가 나온다.
  - **업데이트 내용**: 카드의 "업데이트 내용"을 펼치면 무엇이 바뀌었는지 나온다. "웹에서 자세히 보기"로 배포 페이지를 연다.
  - **지금 업데이트**: 누르면 새 버전을 내려받아, 이 앱과 같은 개발자가 서명했고 Apple 공증을 받았는지 확인한 뒤, 앱이 잠깐 꺼졌다가 새 버전으로 다시 열린다. 터미널은 필요 없다. 경기 중에는 누를 수 없다. 검사에서 어긋나면 아무것도 바꾸지 않고 이유를 보여 준다.
  - 0.2.1까지의 앱에는 이 버튼이 없으므로, 그 버전에서는 설치 명령을 한 번 더 실행해야 한다. 소스로 직접 만든 앱도 명령으로 업데이트한다.
  - 설정 탭에서 자동 확인을 끌 수 있다.
- 설치 명령은 실행 중인 앱을 끄고 새 버전으로 바꾼 뒤 다시 연다. 하던 선수가 그대로 이어진다.
- **초기화**: 설정 탭 맨 아래의 "초기화" 카드에서 한다. "○○ 처음부터 다시"는 지금 하는 모드만, "전체 초기화"는 모든 모드를 비운다. 누르면 한 번 더 묻는다. 저장 파일은 지우지 않고 저장 폴더 안의 `backups/날짜-시각/`으로 옮겨 두므로, 그 파일을 원래 자리(`~/Library/Application Support/TokenBaseball`)로 다시 옮기면 예전 선수가 돌아온다. "저장 폴더 열기"로 그 폴더를 Finder에서 연다.
- 아직 배포되지 않은 최신 변경까지 쓰려면 설치 명령 끝에 `-s -- --build`를 붙여 소스로 직접 만든다 (Xcode 필요).

## 세 종목에 공통인 것

- **토큰이 훈련 포인트다.** Claude Code, Codex, Gemini CLI, opencode에서 쓴 토큰을 로컬 로그에서 읽는다. 1토큰이 1 P다. 선수를 만든 뒤에 쓴 토큰만 세고, 20초마다 반영된다.
- **경기는 1시간에 한 번.** 경기 기회는 1시간에 하나씩, 최대 3개까지 쌓인다. 기회가 없을 때는 다음 경기 카드에 "다음 경기까지 23분 · 오후 3:40에 가능"처럼 남은 시간과 시각, 채워지는 막대가 나온다. "경기 시작"을 직접 눌러야 하고, 한 경기는 실시간 문자 중계로 15분쯤 걸린다.
- **배속.** 경기 탭 맨 위의 배속 카드에서 1× · 2× · 4× · 8×를 고른다. 경기 도중에도 바꿀 수 있고 다음 경기에도 이어진다. 8배속이면 한 경기가 2분쯤이다. 기다리는 시간만 줄 뿐 경기 내용과 결과는 같다.
- **결과 바로 보기.** 배속 카드의 "결과 바로 보기 · 1.0M P" 버튼을 누르면 훈련 포인트 100만을 내고 남은 경기를 곧바로 끝까지 치른다. 경기 도중에도 쓸 수 있고, 결과는 끝까지 지켜봤을 때와 같다. 여러 번 써도 값이 오르지 않는다. 건너뛴 뒤로는 플레이 스타일을 바꿀 수 없다.
- **토큰으로 바로 경기.** 경기 기회가 없을 때 다음 경기 카드의 "바로 경기" 버튼으로 기회를 하나 사서 곧바로 시작한다. 값은 훈련 포인트 300만이고, 연달아 사면 600만, 1,200만으로 두 배씩 오른다. 경기 기회가 저절로 하나 생기면 다시 300만으로 돌아간다. 이렇게 치른 경기에서는 실전 경험으로 능력이 조금 오른다 (평점이 좋을수록 많이, 0.02~0.1).
- **6부 리그.** 6부 시민 아마추어에서 시작해 1부 프로까지 올라간다. 야구는 리그마다 10팀이 36라운드를, 축구는 20팀이 38라운드를, 농구는 10팀이 36라운드를 치르고, 시즌이 끝나면 플레이오프와 친선 5경기를 치르는 오프시즌이 있다.
- **승격과 강등은 반드시 있다.** 방식은 종목마다 다르다. 야구와 농구는 직접 만든 방식(와일드카드 + 승강 플레이오프), 축구는 잉글랜드 리그 방식(1·2위 자동 승격, 3~6위 플레이오프로 한 팀 더, 아래 세 팀 강등)이다 → [리그](../03-league.md#승강).
- **컵대회.** 리그와 별개로 모든 구단(야구 60개, 축구 120개, 농구 60개)이 나오는 단판 승부 대회가 시즌마다 열린다. 리그 사이사이에 한 라운드씩 열리고 (야구와 농구 여섯 라운드, 축구 일곱 라운드), 윗 리그 구단을 잡으면 명성이 크게 오른다.
- **모드를 바꾸면 홈으로.** 설정 탭에서 야구 선수, 축구 선수, 농구 선수를 바꾸면 그 모드의 홈 화면이 바로 나온다.
- **훈련.** 어떤 훈련이든 능력이 같은 양만큼 오르고, 경기 사이에 다섯 번까지 한다. 지금 리그 수준을 넘으면 윗 리그로 올라가야 더 훈련할 수 있다.
- **모드는 따로 저장된다.** 설정 탭의 "모드"에서 오간다. 한 번에 하나만 진행하고, 쉬는 쪽은 그동안 쓴 토큰을 받지 않으며 경기 기회도 쌓이지 않는다.
- **상단바.** 평소에는 내 선수가 훈련하는 모습과 숫자 하나(훈련 포인트, 오늘 사용량, 다음 경기까지 남은 시간 중 설정에서 고른 것)가 나온다. 경기 중에는 스코어가 나온다. 설정에서 훈련 애니메이션을 끄면 그 자리에 도트로 그린 야구공(축구는 축구공, 농구는 농구공)이 나온다. 경기 중에도 공이 나온다.

경기 규칙과 훈련, 승강제는 축구·야구 전문가 관점의 검토를 거쳐 고쳤다. 무엇을 지적받고 무엇을 고쳤는지는 → [전문가 검토](../review/README.md).

화면 그림은 `TOKEN_BASEBALL_SNAPSHOT=폴더 swift run TokenBaseball`로 뽑은 예시 화면이다. 구단과 선수 이름은 모두 가상이다.
