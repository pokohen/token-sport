# 축구 구단 경영

시민 축구단의 구단주가 되어, 코딩하며 쓴 토큰을 자금 삼아 6부에서 1부 프로 리그까지 올라간다.
자금, 시설, 홍보, 영입, 승격의 틀은 [야구 구단 경영](baseball-club.md)과 같다. 여기서는 **축구에서 달라지는 것**을 중심으로 적는다.

[플레이 가이드 목록](README.md) · 규칙의 근거: [축구 모드](../07-football.md), [리그](../03-league.md#축구-잉글랜드-방식) · 전문가 검토: [축구 검토](../review/football.md)

> ⚠️ **구단 경영 모드는 지금 앱에서 뺐다.** 코드와 저장 파일은 남아 있지만 앱에서 고를 수 없고, 예전에 구단을 하던 저장 파일도 선수 모드로 열린다. 이 가이드는 기록으로 남겨 둔다. 지금은 선수 키우기([야구](baseball-player.md), [축구](football-player.md), [농구](basketball-player.md))가 중심이다.

## 시작하기

1. (예전 방식) 모드에서 **축구 구단**의 "새로 만들기"를 누른다.
2. 연고지, 팀 이름, 팀 색상과 엠블럼을 정한다. 팀 이름을 비우면 "○○ 시민 FC"가 된다.
3. "구단 창단"을 누르면 6부 리그에서 선수 16명(골키퍼 2, 수비수 5, 미드필더 5, 공격수 4), 자금 ₩100,000으로 시작한다.

야구 구단을 이미 갖고 있어도 따로 만들 수 있다. 둘은 저장 파일이 다르고, 한 번에 한 구단만 토큰을 받는다.

## 야구와 다른 점

| | 야구 구단 | 축구 구단 |
|---|---|---|
| 순위 | 승률 | **승점** (승 3, 무 1, 패 0). 같으면 골득실 → 다득점 → 상대 전적 |
| 무승부 | 연장 11회까지 가도 동점일 때만 | 흔하다 |
| 경기 진행 | 공 하나씩 | 경기 시간 20초씩 |
| 경기 전에 정하는 것 | 타순, 선발 투수, 투수 운용 방침 | 선발 11명, **포메이션**, **전술 성향** |
| 경기 중 교체 | 투수만 (방침대로) | 60분 이후 지친 선수부터 자동, 최대 5명 |
| 승격과 강등 | 1팀 자동 + 와일드카드와 승강 플레이오프 | **잉글랜드 방식**: 3팀 승격·3팀 강등, 3~6위 승격 플레이오프 |
| 승격 조건 | 신청 + 인지도 + 신청비 | **구장 등급** (경기장 레벨). 신청 없음 |
| 출장 정지 | 없음 | 퇴장 1경기, 시즌 경고 5장마다 1경기 |
| 이적 기간 | 오프시즌 + 24라운드까지 | 여름(오프시즌 + 1~3라운드)과 겨울(17~20라운드) |
| 신인 | 신인 드래프트 | 유소년 승급 |
| 연봉 | 시즌마다 오른다 | 계약 기간 동안 그대로 |
| 선수 능력치 | 타자 6개, 투수 4개 | 슈팅, 패스, 드리블, 수비, 스피드, 피지컬, 골키핑, 체력 |

## 홈 탭

<img src="../images/football-club/home.png" alt="축구 구단 홈 탭" width="380">

야구 구단과 같은 구성이다. 전적 옆에 승점이 함께 나오고, 다음 경기 카드에 상대의 예상 포메이션이 보인다.

## 경기 탭: 포메이션과 전술

<img src="../images/football-club/match.png" alt="축구 구단 경기 탭" width="380">

경기 전에 **포메이션**과 **전술 성향**을 정한다. 경기 중에는 개입할 수 없다.

| 포메이션 | 특징 |
|---|---|
| 4-4-2 | 기본형. 강한 곳도 약한 곳도 없다 |
| 4-3-3 | 공격수 3명. 상대 진영에서 기회를 더 만들지만 중원 싸움에서 밀린다 |
| 4-2-3-1 | 미드필더 5명에 원톱. 중원을 잡지만 상대 진영에서 기회가 줄어든다 |
| 4-1-2-1-2 | 다이아몬드 중원. 중원을 장악하지만 우리 진영 수비가 약해진다 |
| 3-5-2 | 중원이 가장 강하지만 우리 진영 수비가 가장 약하다 |
| 3-4-3 | 기회를 가장 많이 만들지만 뒤가 열린다 |
| 5-3-2 | 우리 진영 수비가 단단하지만 중원 싸움에서 밀린다 |

| 전술 성향 | 효과 |
|---|---|
| 공격적 | 슈팅 기회가 늘지만 실점 위험도 커진다 |
| 균형 | 없음 |
| 수비적 | 실점 위험이 줄지만 슈팅 기회도 줄어든다 |

카드에 **다음 상대의 예상 포메이션**이 나온다. 상대가 중원이 약한 포메이션이면 중원을 잡는 포메이션으로, 상대가 뒤가 열리는 포메이션이면 공격적으로 가 볼 수 있다. 포메이션을 바꾸면 선수 구성(수비수·미드필더·공격수 인원)이 맞는지 선수 탭에서 확인한다.

### 중계

<img src="../images/football-club/live.png" alt="축구 경기 중계" width="380">

- 맨 위에 스코어와 경기 시간, 두 팀의 포메이션.
- 가운데 띠는 공이 있는 곳이다: 우리 진영 / 중원 / 상대 진영. 화살표가 지금 공격하는 팀을 알려 준다.
- 점유율, 슈팅(유효), 코너킥, 반칙, 경고·퇴장.
- 문자 중계와 다른 구장 소식.

전·후반 45분에 추가시간이 붙고, 골·하프타임·교체·퇴장 장면에서는 잠깐 멈췄다 간다. 한 경기는 야구와 같이 15분쯤 걸린다.

## 선수 탭: 선발 11명

<img src="../images/football-club/lineup.png" alt="축구 구단 선발 11명" width="380">

- 포메이션의 자리마다 "교체"로 선수를 바꾼다. 손대지 않으면 능력 순으로 자동 구성된다.
- **골키퍼는 반드시 1명** 들어가야 한다. 골키퍼 1명을 포함해 11명이 없으면 경기를 시작할 수 없다.
- 제 포지션이 아닌 자리에 서면 주황색으로 표시되고 능력이 깎인다.
- **벤치**의 선수는 60분 이후 지친 선수부터 같은 포지션끼리 자동으로 교체된다 (한 경기 5명까지).

## 리그 탭

<img src="../images/football-club/league.png" alt="축구 구단 리그 탭" width="380">

순위표에 승점과 골득실이 나온다. 팀을 눌러 선수단을 보고 이적 제안을 보내는 방법은 야구 구단과 같다. **승격과 강등은 잉글랜드 리그 방식**이라 야구와 다르다.

### 승격과 강등

| 정규시즌 순위 | 결과 |
|---|---|
| **1위, 2위** | 자동 승격 |
| **3~6위** | **승격 플레이오프**. 이긴 한 팀이 승격한다 |
| 7~17위 | 잔류 |
| **18~20위** | 자동 강등 |

**승격 플레이오프**

| 단계 | 대진 | 방식 |
|---|---|---|
| 준결승 1차전 | 3위 대 6위, 4위 대 5위 | 순위가 **낮은** 팀의 홈. 90분에 끝나고 비길 수 있다 |
| 준결승 2차전 | 같은 대진 | 순위가 **높은** 팀의 홈. 두 경기의 골을 합산해 많은 팀이 올라간다. 합산이 같으면 연장 → 승부차기. 원정 다득점 규칙은 없다 |
| 결승 | 준결승 승자끼리 | **중립 구장 단판**. 홈 이점이 없다. 비기면 연장 → 승부차기 |

- 내 구단이 나가면 최대 세 경기를 치른다.
- 야구처럼 윗 리그 팀과 맞붙는 승강전은 없다. 18위부터는 그대로 강등이라, **17위 안에 드는 것**이 잔류 조건이다.

**구장 등급**

신청은 필요 없다. 대신 시즌이 끝날 때 **경기장 레벨**이 기준에 닿아 있어야 한다. 리그 탭의 "승격 조건: 구장 등급" 카드에 지금 레벨과 필요한 레벨이 나온다.

| 승격 | 6부 → 5부 | 5부 → 4부 | 4부 → 3부 | 3부 → 2부 | 2부 → 1부 |
|---|---|---|---|---|---|
| 필요한 경기장 | Lv2 | Lv3 | Lv4 | Lv5 | Lv6 |

기준에 못 미치면 1위를 해도 승격 자격이 다음 순위 팀으로 넘어간다. **승격을 노리는 시즌에는 경기장부터 올린다.**

## 카드와 출장 정지

- 경고 두 장이면 퇴장이고, 그 경기를 10명으로 치른다. 한 명이 모자라면 공격과 수비 모두 눈에 띄게 밀린다.
- **퇴장한 선수는 다음 리그 한 경기**, **시즌 경고가 다섯 장 쌓인 선수는 한 경기**를 쉰다. 로스터에 "출장 정지"로 표시되고, 선발과 벤치에서 자동으로 빠진다.
- 정지 선수가 나오면 그 포지션의 벤치 선수가 선발로 올라간다. 포지션마다 여유 인원을 두는 이유다.
- 새 시즌이 시작되면 경고와 정지가 지워진다.

## 이적 기간, 유소년 승급, 연봉

| | 내용 |
|---|---|
| **이적 기간** | 여름(오프시즌 친선 5경기 + 개막 뒤 3라운드)과 겨울(17~20라운드) 두 번. 이 기간에만 다른 구단과 선수를 주고받는다 |
| **무소속 선수** | 이적 기간이 아니어도 언제든 계약을 제안할 수 있다 |
| **유소년 승급** | 축구에는 드래프트가 없다. 오프시즌 친선 3경기 뒤에 유소년 팀에서 16~18세 후보 세 명이 올라오고, 한 명을 고른다. **훈련소 레벨이 높을수록 잠재력 높은 선수**가 나온다. 다른 구단도 저마다 유소년을 올린다 |
| **연봉** | 계약 기간 동안 그대로다. 재계약할 때 선수가 인상을 요구하고, 승격하면 10% 오른다 |

## 나이

축구 선수의 나이 곡선은 야구와 다르다.

| | 빠르게 성장 | 성장이 멈춤 | 스피드·체력이 내려가기 시작 | 본격적으로 하락 |
|---|---|---|---|---|
| 필드 선수 | 21세까지 | 29세 | 30세 | 33세 |
| 골키퍼 | 23세까지 | 32세 | 33세 | 35세 |

영입할 때 필드 선수는 20대 초반, 골키퍼는 20대 후반도 충분히 젊다.

## 처음 며칠의 요령

1. 시작 선수단은 포지션별 인원이 빠듯하다. 퇴장이나 계약 만료에 대비해 **골키퍼 2명**은 꼭 유지한다.
2. 선수 구성에 맞는 포메이션을 고른다. 공격수가 약하면 4-2-3-1, 수비수가 약하면 수비수 3명 포메이션은 피한다.
3. 체력이 낮은 선수가 많으면 후반에 무너진다. 훈련 방침에서 체력 비중을 조금 올린다.
4. 승점제라 비기는 것도 쌓인다. 강한 상대 원정에서는 수비적으로 가는 것도 방법이다.
5. 승격을 노리면 **경기장 레벨을 먼저** 본다. 6위 안에 들어도 구장 등급이 모자라면 플레이오프에 나가지 못한다.
