# Token Sports

AI 코딩 도구에서 쓴 토큰이 **훈련 포인트**가 되는 macOS 메뉴바 선수 키우기 게임.
**야구 선수**, **축구 선수**, **농구 선수** 가운데 한 명이 되어, 16세에 6부 시민 구단에 입단하고, 코딩하며 쌓인 포인트로 훈련해 1부 프로 리그의 스타까지 올라간다.

> Token Sports는 **KBO를 비롯한 실제 리그·구단과 무관한 비공식 팬 프로젝트**입니다. 등장하는 구단과 선수는 모두 가상입니다.

## 어떤 게임인가

- **토큰이 곧 훈련**: Claude Code, Codex, Gemini CLI, opencode에서 쓴 토큰이 그대로 훈련 포인트로 쌓인다. 평소처럼 일하면 내 선수가 큰다.
- **야구, 축구, 농구 선수**: 야구는 타자(9개 포지션)나 투수(선발·불펜), 축구는 골키퍼·수비수·미드필더·공격수, 농구는 포인트 가드·슈팅 가드·스몰 포워드·파워 포워드·센터 중에 고른다. 셋은 따로 저장되고 설정 탭에서 오갈 수 있다.
- **훈련**: 티 배팅, 웨이트, 불펜 피칭, 슈팅 연습 같은 훈련을 골라 능력을 올린다. 경기 사이에 다섯 번까지 하고, 능력치가 높을수록 포인트가 많이 든다. 윗 리그일수록 한 번에 더 많이 크지만 값도 비싸다. 지금 리그 수준을 넘어서면 윗 리그로 올라가야 더 클 수 있다.
- **상단바에서 진행**: 상단바 아이콘을 누르면 홈, 경기, 리그, 훈련, 커리어, 설정 탭이 열린다. 경기 중에는 상단바에 스코어가 뜬다.
- **실시간 문자 중계**: 야구는 공 하나씩, 축구는 경기 시간 20초씩, 농구는 8초씩 진행된다. 내 선수가 나온 장면은 강조되고, 지금까지의 평점이 실시간으로 보인다. 한 경기는 15분쯤이고 **배속(1×·2×·4×·8×)** 으로 줄이거나, 토큰을 내고 **결과 바로 보기**로 건너뛸 수 있다.
- **경기는 한 시간에 한 번**: 경기 기회는 1시간에 하나씩 최대 3개까지 쌓인다. 기다리기 싫으면 **훈련 포인트로 사서 바로** 치를 수 있다.
- **출전**: 야구 타자는 매 경기 선발로 나오고, 투수는 등판 간격대로 나온다. 축구 선수는 실력으로 주전을 따내야 하고, 선발이 아니면 후반에 교체로 들어간다. 농구 선수도 선발을 따내야 하고, 벤치에서 시작하면 감독 신뢰에 따라 8~24분을 뛴다. 축구와 농구는 경기 전에 플레이 스타일을 고른다.
- **평점, 감독 신뢰, 명성**: 경기마다 평점이 나온다. 잘하면 감독 신뢰가 올라 더 중요한 자리를 맡고, 명성이 오르면 더 큰 구단에서 제안이 온다.
- **컵대회**: 모든 구단(야구 60개, 축구 120개, 농구 60개)이 나오는 단판 승부. 6부 구단으로 1부 구단을 잡으면 명성이 크게 오른다.
- **컨디션, 기세, 라이벌**: 경기마다 컨디션이 달라지고, 활약이 이어지면 기세가 붙는다. 같은 리그의 비슷한 선수가 라이벌이 되어 맞대결 전적이 쌓인다.
- **명성 활동**: 팬 사인회, 방송 인터뷰, 유소년 교실 봉사에 포인트를 들여 명성을 직접 올릴 수 있다.
- **스카우트**: 다른 구단의 스카우트가 나를 지켜보고, 경기마다 평점에 따라 관심도가 오르내린다. 가끔 직접 보러 오는 경기는 두 배로 반영된다. 관심이 쌓인 구단이 이적 기간에 제안을 보낸다. 제안은 지금 리그에서 두 리그 위까지의 구단에서 온다.
- **계약과 이적**: 스카우트의 이적 제안, 재계약, 방출 뒤의 입단 제안. 소속 구단이 승격하면 함께 올라간다. 한 시즌을 마치면 오프시즌에 은퇴할 수 있고, 커리어 기록은 명예의 전당에 남는다.
- **살아 있는 세계**: 6부 리그의 모든 구단(야구와 농구는 리그마다 10팀, 축구는 20팀)이 CPU로 운영된다. 다른 선수들도 성장하고 은퇴하며, 구단은 승격하고 강등된다.

화면과 플레이 방법을 그림과 함께 정리한 가이드:

- ⚾ [야구 개인 성장](docs/guide/baseball-player.md)
- ⚽ [축구 개인 성장](docs/guide/football-player.md)
- 🏀 [농구 개인 성장](docs/guide/basketball-player.md)

규칙의 근거와 수치는 [기획 문서](docs/README.md)에 있다. 경기 규칙, 훈련, 승강제는 축구·야구 전문가 관점의 검토를 거쳐 고쳤다 → [전문가 검토](docs/review/README.md).

구단주가 되어 구단을 운영하는 모드(야구 구단, 축구 구단)는 처음에 만들었지만, 지금은 선수 키우기에 집중하려고 **앱에서 뺐다.** 코드와 예전 저장 파일은 남아 있다.

## 설치

터미널에 이 한 줄을 붙여 넣는다. 저장소를 직접 받을 필요가 없다.

```sh
curl -fsSL https://raw.githubusercontent.com/pokohen/token-sport/main/Scripts/install.sh | bash
```

- **배포 파일이 올라와 있으면** 서명·공증된 앱을 내려받아 응용 프로그램 폴더에 넣고 실행한다. 몇 초면 끝나고 **Xcode가 없어도 된다.**
- 배포 파일이 아직 없으면 소스를 `~/.token-sport`에 받아 이 맥에서 앱을 만든다. 이때는 Xcode 16 이상이 필요하고 1~2분 걸린다.
- **업데이트도 같은 명령**이다. 선수 저장 파일은 건드리지 않는다.
- 아직 배포되지 않은 최신 변경까지 쓰고 싶으면 끝에 `-s -- --build`를 붙인다 (`… | bash -s -- --build`). 소스로 직접 만든다.
- 지우려면 응용 프로그램 폴더에서 Token Sports를 휴지통에 넣는다. 저장 파일은 `~/Library/Application Support/TokenBaseball`에 남는다.

[GitHub Releases](https://github.com/pokohen/token-sport/releases)에서 `.dmg`를 직접 받아, 열고, 앱을 응용 프로그램 폴더로 끌어다 놓아도 된다.

**필요한 것**

- macOS 14 (Sonoma) 이상. 인텔 맥과 애플 실리콘 맥 모두 된다
- 소스로 직접 만들 때만: Xcode 16 이상 (Swift 6)

### 직접 받아서 빌드하기 (개발할 때)

**1. 받기**

```sh
git clone https://github.com/pokohen/token-sport.git
cd token-sport
```

git을 쓰지 않으면 GitHub 저장소 페이지의 **Code → Download ZIP**으로 받아 압축을 풀어도 된다.

**2. 앱 만들기**

```sh
Scripts/make-app.sh
```

`build/Token Sports.app`이 생긴다. 처음에는 빌드에 1~2분 걸린다.

**3. 실행**

```sh
open "build/Token Sports.app"
```

- 상단바(메뉴 막대)에 아이콘이 생긴다. Dock에는 나타나지 않는다.
- 아이콘을 누르면 야구 선수, 축구 선수, 농구 선수 중에 고르는 화면이 나온다.
- 처음 실행하면 알림을 허용할지 묻는다. 경기 종료와 득점 소식을 알림으로 받는다.
- 계속 쓰려면 앱을 응용 프로그램 폴더로 옮긴다: `cp -R "build/Token Sports.app" /Applications/`
- 맥을 켤 때 자동으로 실행하려면 **시스템 설정 → 일반 → 로그인 항목**에 앱을 추가한다.
- 끝낼 때는 설정 탭의 **앱 종료**를 누른다.

직접 빌드한 앱이라 보통은 바로 열린다. ZIP으로 받았거나 다른 맥에서 만든 앱을 옮겨 와서 "확인되지 않은 개발자" 경고가 나오면, Finder에서 앱을 **우클릭 → 열기**로 한 번 열어 준다.

**업데이트** (저장 파일은 그대로, 코드만 새로)

```sh
Scripts/update.sh
```

최신 코드를 받아 앱을 다시 만든다. 구단과 선수는 그대로 이어진다. 실행 중인 앱을 끄고 새로 만든 앱을 연다.

앱이 새 버전을 알려 주기도 한다. 켤 때와 여섯 시간마다 새 변경이 있는지 확인해서, 있으면 알림을 한 번 보내고 팝오버 위쪽과 설정 탭의 "업데이트" 카드에 표시한다. 카드의 "명령 복사"로 위 명령을 복사할 수 있다. `Scripts/make-app.sh`로 만든 앱에서만 동작하고, 설정 탭에서 끌 수 있다.

**초기화** (처음부터 다시)

앱 안에서 하려면 설정 탭 → **초기화**: 지금 모드만 또는 전체를 처음부터 다시 시작한다. 저장 파일은 지우지 않고 저장 폴더의 `backups/날짜-시각/`으로 옮겨 둔다. 아래 스크립트는 저장소를 직접 받아 쓰는 경우에 코드까지 새로 받는 방법이다.

```sh
Scripts/reset.sh
```

무엇을 하는지 보여 주고 확인을 묻는다.

1. 저장 파일(구단·선수)을 백업 폴더로 옮긴다. 지우지는 않는다: `~/Library/Application Support/TokenBaseball-backup-날짜-시각`. 되돌리려면 그 폴더 이름을 `TokenBaseball`로 바꾼다.
2. 코드를 원격 저장소의 최신 상태로 새로 받는다.
3. 빌드 결과를 지우고 앱을 처음부터 다시 만든다.

직접 고친 파일이나 올리지 않은 커밋이 있으면 두 스크립트 모두 아무것도 하지 않고 멈춘다. 확인 없이 초기화하려면 `Scripts/reset.sh --yes`.

**삭제**

앱을 지우고, 저장 파일까지 없애려면 `~/Library/Application Support/TokenBaseball` 폴더를 지운다.

## 알아 둘 것

- 토큰 사용량은 `~/.claude/projects`(Claude Code), `~/.codex/sessions`(Codex), `~/.gemini/tmp`(Gemini CLI), `~/.local/share/opencode`(opencode)의 로컬 로그에서 읽는다. 외부로 보내지 않는다. Gemini CLI와 opencode는 각 도구의 소스 코드를 보고 만들었고, 실제 로그로는 아직 확인하지 못했다.
- 이 앱이 하는 네트워크 요청은 **새 버전 확인 하나뿐**이다. GitHub에 "이 빌드 뒤로 변경이 몇 개 쌓였는지"만 묻고, 보내는 것은 저장소 이름과 빌드한 버전(커밋)뿐이다. 토큰 사용량과 게임 내용은 보내지 않는다. 설정 탭의 "새 버전 자동 확인"을 끄면 요청하지 않는다.
- 선수를 만든 뒤에 쓴 토큰만 훈련 포인트가 된다. 20초마다 반영된다.
- 게임은 `~/Library/Application Support/TokenBaseball` 폴더에 저장된다: 야구 선수는 `save-baseball-player.json`, 축구 선수는 `save-football-player.json`, 농구 선수는 `save-basketball-player.json`. 이 폴더를 복사해 두면 백업이 된다.
- 경기 기회는 1시간에 하나씩, 최대 3개까지 쌓인다. 경기 한 번은 1배속으로 15분쯤 걸린다. 배속은 경기 탭에서 고르고 경기 도중에도 바꿀 수 있다. 같은 카드의 "결과 바로 보기"(100만)를 누르면 남은 경기를 곧바로 끝낸다.
- 경기 기회가 없을 때는 훈련 포인트 300만으로 하나를 사서 바로 치를 수 있다. 연달아 사면 두 배씩 비싸지고, 기회가 저절로 하나 생기면 처음 값으로 돌아간다.
- 야구 선수, 축구 선수, 농구 선수는 따로 저장된다. 설정 탭에서 모드를 바꾸면 그쪽으로 넘어가고, 없으면 새로 만든다.
- 한 번에 하나만 진행한다. 쉬는 선수는 그동안 쓴 토큰을 받지 않고 경기 기회도 쌓이지 않는다.

## 개발

```sh
swift run TokenBaseball        # 앱 번들 없이 바로 실행 (알림은 나오지 않음)
swift test                     # 테스트
TB_STRESS=1 swift test --filter StressTests   # 여러 시드 장기 시뮬레이션 (야구 6분, 축구 9분쯤)
```

진짜 구단을 건드리지 않고 시험하려면 저장 위치를 바꿔 실행한다. 직접 눌러 확인할 항목은 [테스트 안내](docs/TESTING.md)에 있다.

```sh
TOKEN_BASEBALL_SAVE=/tmp/tb-test.json swift run TokenBaseball
```

## 개발용 환경 변수

| 변수 | 내용 |
|---|---|
| `TOKEN_BASEBALL_SAVE` | 저장 파일 위치를 바꾼다 (축구 저장 파일과 종목 표시 파일도 같은 폴더에 생긴다) |
| `TOKEN_BASEBALL_SNAPSHOT` | 각 화면을 이 폴더에 PNG로 그리고 끝낸다 (임시 게임 사용, 축구 화면은 `football/`, 선수 모드는 `career/`, `career-pitcher/`, `career-football/`, `career-keeper/`, `career-basketball/` 아래) |
| `TOKEN_BASEBALL_SELFTEST` | 화면 없이 앱 흐름을 점검하고 끝낸다: 만들기 → 훈련 → 경기 → 모드 전환 → 다시 켜기 (이 폴더에 임시 저장 파일을 만든다. 폴더 안의 내용은 지워진다) |
| `TOKEN_BASEBALL_CHECK_UPDATE` | 새 버전 확인만 하고 결과를 출력한 뒤 끝낸다 |
| `TOKEN_BASEBALL_RELEASE_VERSION` | 배포 파일로 설치한 이 버전의 앱인 것처럼 새 버전을 확인한다 (예: `0.1.0`) |
| `TOKEN_BASEBALL_SELF_UPDATE` | 화면 없이 앱 안 업데이트를 끝까지 해 본다: 내려받고, 서명·공증을 검사하고, 앱을 바꾼다 (다시 열지는 않는다). 앱 번들로 실행해야 한다 |
| `TOKEN_BASEBALL_UPDATE_DMG` | `TOKEN_BASEBALL_SELF_UPDATE`에서 내려받는 대신 이 dmg 파일로 업데이트해 본다 |
| `TOKEN_BASEBALL_BUILD_COMMIT` | 빌드한 버전(커밋)을 이 값으로 본다 (새 버전 확인을 시험할 때) |
